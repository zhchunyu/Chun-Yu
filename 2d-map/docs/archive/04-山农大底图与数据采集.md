## 2. 已落地：本地卫星影像底图（无需登录）

项目已内置山西农业大学校园范围的 **Esri World Imagery** 卫星影像本地瓦片：

| 项 | 值 |
|----|----|
| 位置 | `web/lib/tiles/satellite/{z}/{x}/{y}.jpg` |
| 数量 | 832 片，约 9.9 MB（无失败、无空片） |
| 范围 | z14：112.544~112.588 / 37.457~37.405<br>z15~z17：112.555~112.604 / 37.449~37.405<br>z18（核心区）：112.565~112.591 / 37.431~37.416 |
| 层级 | z14~z17 全范围 + z18 校园核心区 |
| 用途 | ① 前端默认底图 ② QGIS 里描摹真实校园的参照 |

- 前端：`web/main.js` 已加 "校园卫星影像（本地）" 图层并设为默认，离线可用；
  并设 `maxNativeZoom: 18`，再放大由 Leaflet 拉伸而不是去请求不存在的瓦片。
- **版权**：影像版权归 Esri / Maxar / Earthstar Geographics，
  前端已保留 attribution；仅限校内课程项目等非商业用途，不要公开分发瓦片。

> ⚠️ **格式坑（已修复）**：Esri World_Imagery 返回的瓦片字节是 **JPEG**，不是 PNG。
> 早期一版把它们存成了 `*.png`，导致 `http.server` 按 `image/png` 发送、与实际字节不符。
> 现已改名为 `*.jpg`，并让下载脚本按魔数自动判定后缀。
> 重新抓取时用默认的 `--ext auto`，既不会写错后缀，
> 也不会把 SSO 跳转页/错误页当成瓦片存下来（非图片一律判为失败）。

### 抓取/扩充命令（scripts/fetch_tiles.py，可断点续传）

```bash
# 扩充 z19 核心区（约 0.15 m/像素），或调整 bbox 重抓；已存在的瓦片自动跳过
python scripts/fetch_tiles.py ^
  --url "https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}" ^
  --bbox 112.570 37.418 112.588 37.428 --zooms 19 --out web/lib/tiles/satellite

# 换其它影像源同理，只要 URL 模板含 {z} {x} {y}
```

## 3. QGIS 里描摹真实校园（推荐路线）

1. QGIS → `浏览器面板 → XYZ Tiles → 新建连接`：
   - 名称：Esri影像；URL：
     `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}`
     （在线加载，最高 z19，约 0.3m/像素）
   - 或直接把本地瓦片目录 `web/lib/tiles/satellite` 拖进 QGIS 离线用。
2. 工程 CRS 设 EPSG:3857 或 4326，定位到山农大
   （中心约 `112.5785, 37.4229`，可直接把这对经纬度粘到定位框）。
3. 按 `docs/01` 建 buildings/roads/footways/nodes 四图层，
   对着影像描摹 → 导出 `data/raw/*.geojson` → 双击 `重建路网.exe` → 前端即显示真实校园路网。

## 4. 登录后采集官方站数据（待你登录）

1. 在浏览器打开 `https://map.sxau.edu.cn/`，用**你的校园账号**登录；
2. 登录成功、地图正常显示后，回到 ZCode 说一声"继续抓取"；
3. 我会在该登录会话中：
   - 读取 performance 资源表 + XHR 记录，找出瓦片/矢量接口；
   - 若是矢量数据（GeoJSON/MVT）→ 转成我们的 GeoJSON 图层，价值最大；
   - 若是栅格瓦片 → 用 `fetch_tiles.py` 只抓校园范围离线化。
4. 采集数据仅限本项目课程用途；版权与使用范围遵守学校规定。
