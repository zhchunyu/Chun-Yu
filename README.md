# OurCampus

**从找到一个地点，到一起解决校园里的小事。**

OurCampus 是面向学生的校园地图与社区应用，把地点信息、同学交流和 AUV 校园助手放在同一个入口。找餐厅窗口、查看校园动态、发布失物信息，或带着所选地点向 AI 提问，都可以围绕校园里的具体位置展开。

项目提供 Web 前端源码和 Android 协作体验包，当前处于团队开发与联调阶段。

[应用说明](04-应用开发/OurCampus/README.md) · [Android 1.11 体验包](04-应用开发/OurCampus/docs/apk/OurCampus-1.11-队友图标与开屏.apk) · [团队协作](04-应用开发/OurCampus/docs/团队协作.md)

## 地点信息：先找到，再了解

通过地图或分类搜索校园地点，查看详情、相关动态和餐厅窗口；需要前往时，可以选择起终点、查看路线预览，或进入腾讯地图导航。用户主动点击定位后，应用才获取当前位置。

地点收藏和常用路线帮助保存日常去处。地图坐标仍需逐建筑校准，现有示意路网和路线预览不能作为精确通行依据。

## 社区协作：让信息有地点、有回应

大厅按校园地区组织交流，热点、失物招领和地点反馈可以关联到具体位置。餐厅页面按窗口提供评分与推荐、吐槽筛选，帮助同学围绕具体服务交流。

校园信息流程已实现主动上报、AI 摘要与候选关联、管理员审核和站内消息等环节。普通聊天只有在用户主动提交为动态后才进入分析流程；失物匹配提供寻找线索，物品归属仍由当事人核实。

## AUV 校园助手：带着当前问题提问

AUV 助手提供对话入口，用户可以主动选择地点或课表上下文，让问题与正在查看的校园信息保持联系。模型请求经过登录鉴权和服务端网关，模型密钥保存在服务端。

助手回复用于辅助理解和整理信息；地点状态、活动安排和服务时间仍需结合信息来源与实际情况确认。

| 范围 | 已有实现 | 使用条件与当前边界 |
| --- | --- | --- |
| 地点与地图 | 地点搜索、分类、详情、地图标记、定位入口和路线预览 | 腾讯地图需要有效配置；标签坐标和校园路网仍待校准。 |

| 餐厅窗口与评价 | 窗口详情、评分、筛选和管理员维护；提供云端接入 | 服务器已有相关数据表；多人提交、统计和权限需完成客户端联调。 |
| 校园信息与通知 | 主动上报、AI 分析、审核、订阅和站内消息入口 | 已部署后台工作函数；跨账号处理流程、调度和通知送达仍需逐项验收。 |
| AUV 助手 | 登录后对话、用户主动提供的地点与课表上下文 | 已部署 AI 网关函数；模型连通、权限与客户端调用仍以实际联调为准。 |
| 个人工具 | 收藏、常用路线、附近设施、报修原型与 XLS 课表导入 | 这些工具主要保存在本机；不承诺跨设备工单或教务系统同步。 |
| Android 通知 | 已实现推送 SDK、设备绑定与通知点击入口 | 需配置平台参数、重新打包并做真机测试；当前不作为已验收的后台推送能力。 |

当前服务侧已有 Supabase 项目及 `auv-assistant`、`campus-information-worker` 部署。服务部署和数据表存在是联调基础，完整使用流程以真实账号、双设备及手机实测为准。

Android 1.11 体验包使用 debug 签名，用于团队安装体验与反馈。网页版访问入口将在部署与验收完成后补充。
