# CampusTwin 安全管理模式整合设计

## 背景

「安全管理模式」原本是一套独立源工程（见主仓库 `04-应用开发/安全管理模式/`）：自带域层、自检脚本与深色验证台，但只能在自己的页面里演示。评审要看的是**同一张地图上的安全能力**——风险区、封控路段、人流热力与既有地点、路线、事件同屏，而不是再开一个页面。本次整合把它落到 CampusTwin 主页上。

## 目标

- 安全图层与既有地图同屏：风险区四色圆、人流热力、封控路段虚线、避雨通道高亮、告警地点标签。
- 面板给出态势与处置（人流风控 / 天气联动 / 可信度闸门 / 处置预案 / 处置时效），且与地图叠加层**共用同一份态势**，不出现「面板说高风险、地图没画红圈」。
- 默认关闭：不打开安全模式时，既有界面与体验一行不变。
- 演示可控：无 API Key、无后端也能演完「天气预警 → 预案 → 封路 → 路线绕行」全链路。

## 方案

### 数据来源与接线点

沿用既有真实数据，不引入新数据源：

| 接线点 | 做法 |
| --- | --- |
| 封路 | 预案产出的边 id 写入既有 `affectedEdgeIds` 语义的集合，路线模块 `aStar()` 不改；事件自带封路与预案封路取并集 |
| 人流 | 把既有 `location.crowdStatus`（low/normal/busy）反解为占用率基准（0.22/0.46/0.78）再跑风控；将来接入实测计数只需替换这一层 |
| 天气 | 预置场景快照（W3 方案），升级到实时只需把 `WEATHER_SCENARIOS` 换成服务端代理的 fetch 结果 |
| 坐标 | 复用既有 `worldToMapPosition`，与 `Campus2DViewer` 的 `viewBox="0 0 100 100"` 天然对齐 |

### 面板呈现：居中浮层

面板是独立浮层而不是工具栏抽屉：

- 面板自带不透明卡片底色（纸墨色系）、圆角与投影，**不依赖父容器底色**。
- 视口内居中，宽度 `min(1080px, 100%)`、高度上限约 `88vh`，超高时**面板内部滚动**，标题栏与页脚常驻。
- 正文左右双列（左：图层 / 天气 / 人流 / 时效；右：预警 / 预案 / 联动），宽屏下基本无需滚动；窄屏收成单列，手机横屏恢复双列。
- 收起方式：右上 ×、Esc、点击浮层外。**收起后地图叠加层保留**，便于对照面板结论看地图。
- 从面板点风险行或预警标题时先收起面板，再选中地点，避免详情被浮层遮挡。

### 预警状态机：逐跳推进

预警由 `reported` 起跳，状态机只允许 `reported → extracting → pending → published / verifying`。此前直接跳到 `published`，`advanceAlert()` 对非法跳转**不抛错、只返回 `{ error }`**，预警便静默停在「已上报」，连带「可信度闸门（灰标不打点 / 确认可信）」与「处置预案（一键启动预案）」都没有入口。现按闸门判定的目标状态逐跳推进，并把错误写进 timeline 而不是丢弃。

## 代码范围

- 新增：`src/domain/safety/`（容量口径、人流风控、预警分级、状态机、预案与动作）、`src/app/useSafetyState.js`、`src/data/safetyDemo.js`、`src/features/safety/`（面板与叠加层）。
- 改动：`App.jsx`（态势入口与 `?safety=` 深链接）、`appSettings.js`（4 个布尔设置）、`MapToolbar/MapWorkspace/MapLayerPanel`（工具项、浮层挂载、图层分组）、`campusReducer.js`（安全模式不跨会话恢复）、`styles.css`。
- 不新增运行时依赖，不改路线算法、地图数据与其他业务逻辑。

## 失败处理

- 安全模式默认关闭；`?safety=0` 可显式关闭，图层偏好保留。
- 未接入真实天气或人流数据时，界面明确标注「演示数据」，不伪装成实测。
- 叠加层仅在 2D 场景渲染；3D 场景下打开面板不会报错，只是没有叠加图形。

## 验收

1. `npm test` 全绿（16 文件 / 108 项），`npx vite build` 通过。
2. `/?safety=1&scene=2d` 能看到风险标签与风险圆；暴雨红警下「一键启动预案」可点击，封控路段与避雨通道出现在地图上。
3. 面板在 1500×1000、1280×800、820×900、844×390（手机横屏）下均居中且可滚动，不遮住标题栏与页脚。
4. 收起面板后叠加层仍在；`/` 与 `/?safety=1` 各自回到预期视图。
5. 不打开安全模式时，既有 75 项测试与既有界面不变。

## 实施约束

- 沿用既有 React + CSS，不引入状态管理库或后端依赖。
- 面板与叠加层必须读同一份 `useSafetyState` 结果，禁止各自计算。
- 演示数据与实测数据在 UI 上可区分。
