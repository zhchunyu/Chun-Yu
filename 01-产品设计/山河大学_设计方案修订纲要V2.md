## 零、诊断：为什么"陈旧"

用户的判断准确。问题不在执行精度，在**语言选择**。三条病因：

### 病因 1 · 把"东方"做成了"符号"

已完成的四个阶段（场地骨架 / 中轴尽端 / 中轴序列 / 人文区）全部落在
**牌坊 · 汉阙 · 石狮 · 斗拱 · 飞檐 · 白墙灰瓦**这一套上。

这是**礼制建筑 + 景区建筑**的语言，不是**大学**的语言。
大学的气质来自：**理性、开放、前瞻、学术公共性**。
牌坊与石狮承载的是"门第与仪典"，恰恰与大学精神相反。

### 病因 2 · "新中式"这个词本身已经过期

"白墙灰瓦 + 飞檐翘角"在过去十五年里被地产、文旅小镇、仿古街反复使用，
已经成为一种**高辨识度的商业符号**。它今天的第一联想是"仿古街"，不是"高级"。
用它做一所面向未来的大学，等于**主动选择了一个已被用旧的能指**。

### 病因 3 · D6 的"两路并置"只落地了一路

任务书 D6 定的是 **东方塔阁 + 未来曲面**，靠两路语言在中轴正面对撞制造张力。
但实际执行时，四个阶段全在中轴与人文区 —— **全是塔阁那一路，"未来"从未开工**。
所以现在看到的成果，本质上是**一半的方案**，
而这一半恰好是最容易显得陈旧的那一半。

### 结论

**不是推翻重来，是补齐并转译。**

- 山水格局、中轴序列、风水骨架、场地骨架 —— **全部有效，全部保留**
- 建筑语言 —— **从"符号复刻"改为"原型转译"**，并让"未来"从"一个区"升级为"全区的通用层"

## 一、重构后的主概念

# 藏山纳智 · 云廊书院

> **以山为院 · 以水为径 · 以云为廊**

一句话解释：**把"东方"从屋顶上取下来，放回到空间里；把"未来"从某个区拿出来，铺满整座校园。**

三条策略对应三件事：

| 策略 | 转译的是什么 | 落地手段 | 替代掉的旧做法 |
| --- | --- | --- | --- |
| **以山为院** | 东方"院"的空间原型 | 院落的**堆叠 · 嵌套 · 下沉 · 上屋顶** | 飞檐斗拱的表层符号 |
| **以水为径** | 玉带环腰的滨水格局 | 岸线做成**连续可上人的公共基座** | 孤立的观景台 |
| **以云为廊** | —— | 1.2 km **智慧环廊**，七区全覆盖 | 无（这是新增的未来模块） |

**关键转变**：从"**造形**"（做出一座像古建筑的东西）转向"**造境**"（做出古建筑所承载的那种空间关系，但用当代的方式）。

## 二、设计语言体系（全区统一，替换掉"新中式"）

### 2.1 形态语法：连续曲面 + 编织格构

| 语法 | 说明 | 对应东方的什么 |
| --- | --- | --- |
| **连续曲面** | 屋盖/连廊/雨棚用**变曲率连续曲面**，而不是折线坡屋顶 | 对应"举折"——中式屋面本来就是曲面，只是被简化成了直线坡 |
| **编织格构** | 立面与结构用**斜向交织的格构网格**（钢/木/混凝土肋） | 对应"斗拱"——层层出跳、传力有序，但抽象为网格而非具象构件 |
| **悬浮体量** | 大体量架空、悬挑、错位堆叠，地面层尽量通透 | 对应"台基"——抬高与架空，但让地面还给公共 |

> **一句话**：曲面替代坡屋顶，格构替代斗拱，架空替代台基。
> 三者都是**原型的转译**，不是**符号的复制**。

### 2.2 材料体系

| 部位 | 材料 | 理由 |
| --- | --- | --- |
| 基座 / 台地 | **清水混凝土**（木纹模板） | 厚重、可长期风化、留模板木纹呼应木构 |
| 大跨屋盖 / 连廊 | **胶合木 + 钢节点** | 东方木构的当代做法，暴露结构即装饰 |
| 立面主材 | **超白玻璃幕 + 竹木格栅** | 通透 + 温润，格栅形成"光的编织" |
| 屋面 / 金属包边 | **哑光钛锌板**（深墨灰） | 替代"黛瓦"，但不复制瓦的形制 |
| 锚点构件 | **镜面不锈钢**（仅用于山门 / 漂浮讲堂） | 稀缺使用才有效 |
| 景观 | 毛石、竹、松、水 | 延续山水骨架 |

**克制原则**：镜面不锈钢**只在两个锚点**上出现，用滥了就变成"网红建筑"。

### 2.3 色彩体系

```
墨  #2B2E33   主体金属屋面 / 格构
素  #E8E6E0   清水混凝土 / 石材
木  #C9A87C   竹木格栅 / 胶合木
铜  #B07B45   点缀（栏杆、灯具、标识）—— 用量 < 3%
```

**明确废弃**：`朱漆红 + 黛瓦黑` 这一组（旧方案的木构朱漆与瓦屋面配色）。

## 五、空间体验

**从"礼制序列"改为"学术序列"**：

```
旧：牌坊 → 明堂 → 案山 → 图书馆 → 塔        （仪典感 · 由外而内）
新：山门 → 下沉智谷 → 图书馆 → 垂直书院 → 漂浮讲堂   （公共性 · 由地而天）
```

| 体验层次 | 设计手段 |
| --- | --- |

### 三条最重要的结论

1. **"陈旧"不是材料问题，是构图法则问题。**
   第 1~4 版把黛瓦换成钛锌、朱漆换成铜，读起来还是塔——因为
   **层层出檐 + 逐层收分 + 塔刹** 这套法则没动。删掉这三条，塔形当场就破了。
   同理，后续 R1~R6 里凡是"坡屋顶 + 檐口"的做法，都要先问一句：
   **这是在换材料，还是在换法则？**

2. **"斗拱 → 编织格构"的落点是楼板边带，不是立面外挂。**
   斗拱的本质是**层层出挑的受力构件**，它属于楼板边缘。第 5 版把它罩在立面外，
   立刻变成铁丝笼。第 6 版移进楼板边带（0.90 混凝土 + 1.25 钢桁架），
   立刻读成"结构腰带"——同一种杆件，位置错了就全错。

3. **"错位堆叠"必须靠"每层自成完整的盒"，不能靠"层层相接"。**
   楼板一错位，本层立面的顶边就落在上层楼板轮廓之外。不处理 → 竖翼像断头筷子。
   处理方式不是取消错位，而是**给每层加一条压顶钢轨**，把本层立面收成一个完整体量。
   这才是 BIG 那种堆叠的真实构造逻辑。

### 顺带解决的一个"观感"根因

仰视图一直读成"一摞灰纸片"，最后定位到：**楼板底面是一整片浅灰平面，没有结构表达**。
加一组板底结构肋（墨灰钢，每层 6 根）就解决了。
→ 经验：**大面积的单一平面，永远要给它一点结构**，否则再好的体量也会读成"纸"。

### 四条最重要的结论

1. **竖直镜面对天空是隐形的 —— 这是几何光学，不是口味。**
   站在地面仰视 38~53 m 高的竖直镜面，反射光线朝上打到地平线附近的天空；
   镜面把天空原样还给天空，整片腹板在画面里彻底消失。
   → 镜面只在两个位置成立：**① 人眼高度、正对观看者（映出广场与人）；
   ② 细杆件 / 掠射角、有深色背景（勾出会变的亮边）。**
   本方案的镜面最终落在：山门上下弦（细杆 + 深色腹板背景）、崖面人行高度嵌板、
   智谷玻璃幕的竖向遮阳柱。**"大面镜墙"这个想法本身就是错的。**

2. **地形是零厚度的平面，任何下挖都必须显式补三样东西。**
   ① **挖洞**：`SITE_半岛地形` 是 `cap(P0)` 生成的**单个平铺 n 边形**，没有内部顶点，
      没法"把洞里的点压下去"。用**半平面切开 + 边缘开缺口**（沿 X=0 把半岛切成东西两块，
      各自在切口边上咬掉半个矩形）—— 得到的是**简单多边形**，不需要零宽锁孔缝
      （退化边会让 n 边形三角化结果不可预期）。
   ② **封头**：洞的四壁不会自己出现。南北端各加一块 YZ 截面沿 Y 拉 0.50 m 的实体，
      否则站在谷底朝南北看是"没有底边的洞"。
   ③ **查隐形盖板**：首版谷底全黑的真凶不是谷本身，而是两张横跨谷上方的**大平面**——
      `SITE_水面`（Z 0 的整片 4000×8000 水平面，平地上被 Z 3.0 地形盖住，看不见）
      与 `SITE_分区_中轴人文区`（南边缘 Y 153.6 落在谷里）。
      → **下挖之前，先拿射线投射把"谷口正上方 60 m 内所有对象"列一遍**，
      不要靠读代码猜。诊断脚本：`C:/Users/31967/AppData/Local/Temp/diag_r1.py`。

3. **"玻璃"要分清两种：读作玻璃的，和真的是玻璃的。**
   `make_mat` 做出来的是不透明深蓝灰面板 —— 远景读作玻璃没问题；
   但智谷的玻璃幕后面就是地下实验层，**必须真的透过去**，
   否则"看得见的科学"这个锚点等于没做。用 Principled 的
   `Transmission Weight = 1.0` + `Roughness 0.03` + `IOR 1.45` 单独做一个 `M_GLASST`。

4. **"拱"的读法由**下弦**决定，不由上弦。**
   首版上弦拱到 53、下弦平在 38，整个门架读成"桥面 + 桥拱"，中间那块 15 m 是"桥肚子"。
   把下弦也做成拱（38.5 → 44.0），腹板变成**两端薄、中间厚的月牙**——
   既是拱的弯矩图，洞口也变成"山口"而不是"桥下净空"。

### 顺带修掉的四个静默 bug

- **共面重叠**：`SITE_中轴大道` 的林荫大道段（终点 Y 15.6）与中轴南段（起点 Y −30）
  在 Y −30~15.6 完全重叠且同在 Z 3.06 → 静默 Z-fighting。改成首尾相接。
- **环状布置的构件必须绕自身旋转**：24 段环形坐凳若不传 `box(..., rot=a)`，
  会散成 24 个轴对齐方块（"一堆石头"），拼不成一个环。
- **`make_mat` 按名字缓存 → 同名材质第二次调用的色值被静默丢弃**（压了 3 轮才找到）：
  `make_mat` 开头是 `bpy.data.materials.get(name)`，命中就直接返回。
  各阶段脚本共享同一个 Blender 会话，所以 R1 再调一次
  `make_mat('M_清水混凝土', ...)` 只会把 **R0 那份**拿回来 ——
  把色值从 0.585 压到 0.400、再压到 0.272，画面**毫无变化**。
  → 新规矩：**材质色值只在第一次定义它的阶段写，后续阶段一律
  `bpy.data.materials['M_xxx']` 取引用**；要改就回去改 R0。
- **光照参数是跟着配色标定的，换配色必须重标**：`sun_strength 4.2` / `sky 0.85` /
  曝光 −0.25 这套是按旧配色「黛瓦黑」（反照率 ~0.05）定的。V2 换成浅色系
  （清水混凝土 0.272、素 0.83）后，受光面被直接推到色调映射压缩段顶端 ——
  什么反照率进去都是一片白。**定案：`M_CONC = 0.272` + `sun_strength = 2.9`**，
  两者必须一起改（只压反照率会把阴影一起压黑，只降阳光会让整体发灰）。
  R0 的 6 张成图已按新参数**重新出图**，与 R1 保持一致。

### 四条最重要的结论

1. **纯几何对称的退台 = 金字塔；给它一个方向性，就变成"台地"。**
   图书馆三层轮廓逐层收缩，鸟瞰第一眼读成"塔"。
   破法不是改轮廓，而是**给整栋楼一个方向**：壳与光庭环一起南低北高
   （南 35.40 → 北 38.20，光庭环 3.0 → 5.8 m）。
   轴对称一旦被打破，塔的读法就再也回不来。
   配套两件：**檐口 0**（没有任何一层做出挑的檐）、**塔刹 0**（顶部无尖顶构件）。

2. **薄壳只要外挑，就一定会挡掉自己正下方的光庭带。**
   薄壳的起拱方向是"向内向上"，外缘最低、中心最高。
   壳外缘比光庭环顶低 4.43 m 时，从外面**水平看过去光庭环完全不存在**。
   → 正解：**壳平面 = 顶层轮廓（不外挑）**，外缘正好落在光庭环顶上，
   两者一起倾斜。想要出挑就只能在壳与幕墙同高处收，不能"又出挑又露光庭"。

3. **画面里出现"来历不明的板"，用射线投射问场景，不要猜。**
   讲堂左侧水面上悬着一块灰板，我先后猜过"竖直镜面""对岸远山""对岸陆域切断"，
   全错。`diag_ray.py` 打一条射线过去，一次命中：
   **`BLD_讲堂_玻璃幕`** —— 玻璃幕的西立面在掠射角下把天空反射成一块均匀亮板，
   而它之所以悬空，是因为它**整体错位了 19 m**（见下条）。
   → 规矩：**任何"这块是什么"的问题，都先用 `diag_ray.py` / `diag_vol.py` 回答。**

4. **变曲率薄壳的环数不够，就会被读成"多边形攒尖"。**
   `zf = 起拱 × (1 − s^1.9)` 在 s→1（壳外缘）处斜率最大，
   均匀 5 环时外缘正好折出一圈可见的棱带。
   → 9 环（1600 px 下）才读得出"连续曲面"。**薄壳不是"做个弧形"，是让曲率沿半径变化。**

### 顺带修掉的两个静默 bug

- **`fin_facade` 的 ±X 面玻璃整体错位 ±hy。**
  `side_frames()` 返回的 `(ax,ay)` / `(bx,by)` 是边的**两个端点**，不是中点；
  而玻璃盒在 ±X 分支里错把 `_gy`（起点 y）当成了中点：
  ```python
  gl.append(box((_gx + _ex) * 0.5, _gy, 0.14, abs(_ey - _gy), h, z0))   # ✗
  gl.append(box(_mx, _my, 0.14, abs(_ey - _gy), h, z0))                  # ✓
  ```
  后果：讲堂 hy=19 → 西侧玻璃幕从 Y 842 一直伸到 880（北立面才 861），
  **多出 19 m 悬在水面上空**；图书馆每层错位 28 m。
  → 规矩：**`side_frames` 的两端必须各自取中点，两个分支都要。**

- **树会穿过漂浮建筑的楼板。** 滨水林带与水口植树都会经过半岛尽端。
  体积查询实测：树冠顶点最高到 **Z 13.1**，而讲堂楼板顶才 6.90 —— 树直接长进玻璃幕里。
  → 在**场地阶段**给 `TREE_EXCLUDE` 补 `(0.0, 838.0, 40.0, 38.0)`
  （漂浮讲堂 + 连接桥 + 尽端广场）。树是在场地阶段一次性合并成 `SITE_树干`/`SITE_树冠` 的，
  **晚阶段再想按位置删就晚了。**

### 新增语言：筒壳（barrel vault）—— 把 R2 的壳体系补齐成"一对"

R2 只做出了**四坡壳**。但壳体形式应当**跟着平面长宽比走**：

| 平面 | 壳体 | 中式原型 |
| --- | --- | --- |
| 集中式（图书馆 56×32、美术馆展亭） | **四坡壳**（四面向心收拢） | 庑殿 / 攒尖 |
| 线性（书院四翼 108×22、大礼堂主厅 86×48） | **筒壳**（单向起拱） | 悬山 / 硬山 |

把"悬山"做成四坡壳，等于把长条殿堂压成"平顶 + 一圈薄檐"（阶段 3 首版的老坑）。
**筒壳剖面用 `z = z0 + H·(1 − t^1.8)`**（t = |v|/b）：**脊部平、檐口陡**，
正是中式屋面的"举折"；半圆拱 `1 − sqrt(1−t²)` 是"檐口平、脊部陡"，那是罗马式。

### 五条最重要的结论

1. **"盒子扣壳"一定读成机库 —— 缺的不是曲面，是檐。**
   第 1 版把壳**直接坐在墙上**（书院出檐 1.2 m、大礼堂零出檐）。
   没有檐口线、没有檐下阴影、没有"椽"，变曲率曲面和一根混凝土管子没有区别。
   补上四件事（**出檐 3.0 m + 檐椽 + 铜檐口线 + 楼板压顶线**）之后，
   同一套几何立刻从"物流仓库"变回"殿堂"。**成本极低，收益最大。**

2. **上皮肋只能出横向垄；纵肋一起出，屋面就读成"绗缝被"。**
   第 2 版在壳上皮同时做了纵向肋（沿脊）和横向肋（沿坡），
   正交网格让屋面读成床垫 / 软包。筒瓦的"垄"**只沿坡向**（檐→脊）一道一道排，
   纵向是瓦沟不是凸条。→ `barrel_ribs(side='out', cross=False)`。

3. **`side='out'` 忘了 `lift` 等于没做，而且不会报错。**
   `bar3d` 的截面是绕轴心对称的 r×r，要"坐在壳上皮"就得抬到 `壳厚 + t/2`。
   只写 `side='out'` 而不传 `lift=壳厚`，肋整根埋进壳体内 —— **静默失效**。

4. **`round_rect` 的 4(n+1) 个点全在四个圆角上，直边上一个点都没有。**
   每个圆角弧的起止点就是切点，所以直边没有中间点。
   直接拿它当瓦垄位置，28 道垄会全部挤在四个角。
   → 必须**按弧长重采样**（`_resample_loop`）。又是一个"不报错、只看着不对"的坑。

5. **一个校园里不能有两种壳体。** R3 把"壳必有垄"定成语言之后，
   R2 图书馆的光面薄壳立刻成了例外。→ 在 R3 里**追加**一个
   `BLD_人文_Library_瓦垄` 对象（`build_extra` 共享 globals，R2 的
   `_lib_prof` / `_lib_z` 直接可用），**不动 R2 脚本**，只重出 R2 成图。
   漂浮讲堂**不加垄** —— 它是"悬在水上的曲面平台"，不是屋面，加垄会读成一把伞。

### 一条新增的诊断规矩

**"这个体量看起来不对"——先问场景，不要猜。**
第 2 版的"玻璃山墙看穿到天空"是靠 `diag_vol.py` 查出来筒壳内部是空的
（没有楼板），而不是靠盯图猜。R2 的"悬空灰板"也是靠 `diag_ray.py` 一次命中。
