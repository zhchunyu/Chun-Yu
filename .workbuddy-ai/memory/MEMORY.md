## 5 静默失效六条（**不记住就会白干**；详情见 skill）
1. **变量名 ≠ 材质名**：`bpy.data.materials.get('M_CONC')` **静默返回 `None`** —— 一律用**中文名**（`'M_清水混凝土'`）
2. **`set_in()` 前先问插槽是否被连线**：连线优先，写 `default_value` 无效（本项目 53 个材质中 32 个中招）
3. **`make_mat` 按名字缓存**：同名第二次调用的色值被静默忽略 → 色值只在**第一次定义它的阶段**写
4. **各阶段成图必须用"它自己的 config 链"渲**（`R0_*.png` = R0 阶段的校园，不是"最新配置的 R0 机位"）；
   查漏靠 `check_ab.py` 的**最大差**：配色偏移 ≤ ~50，**200+ 就是几何不一致**
5. **`Haze` 体域会污染 GLB**（导出端已剔除、渲染端已加复用守卫，均验证输出中性）
6. **占位体块 `M_体块_*` 最容易漏出画面**：判据"**比清水混凝土略暗**"（现 0.254~0.324）
- 工具：`check_ab.py`（A/B 量化，**全量重渲前必做**）· `make_ab_configs.py`（切临时 config，自动摘 export）·
  `check_palette.py`（配色验收，**必须分上下半图**，天空天然是蓝的）·
  `_diag_mats.py`（材质连线体检）/ `_diag_blk.py`（占位体块取值）/ `_diag_scene.py` · `diag_grid.py`（全机位射线）

## 8 最高频铁律（**完整 28 条在 skill**）
1. 场地曲面 `flush(up=True)`；总平面显式 `cam_rot:[0,0,0]` + `sun_elev 27°`
2. 坡屋面薄壳：手推法线 + `cap_hole=True`；`roof_ring` 的 `z_in` 必须严格 > `z_out`（写反→倒坡）
3. **"盒子扣壳"一定读成机库 —— 缺的不是曲面，是檐**（出檐 3.0 + 檐椽 + 铜檐口线）
4. **大面积单一平面必须给它结构**（楼板底加肋）；**错位堆叠必须"每层自成完整的盒"**
5. **"大面镜墙"这个想法本身是错的** —— 镜面只在①细杆件掠射角 ②人眼高度正对 ③竖向遮阳柱成立
6. ★ **"取消"类构件的拆除必须提前到"最早重做该区域"的阶段**；**查漏靠 `diag_grid.py` 射线**
7. ★ **"某块读起来太重/太黑"先量体量再谈颜色**（①体量 ②明度 ③光照）—— **多数"太黑"其实是"太厚"**
8. ★ **改配色/光照/材质后先 A/B 量化再决定全量重渲**：平均差 <2 不值得、>6 需要；
   看 **Δ亮度** 与下半图冷暖比，别凭印象
9. **地形是零厚度平面**：下挖要"挖洞 + 端头封头 + 查隐形盖板"
10. 其余（`layered()` 体量 / 下弦起拱 / `skirt_ring` 方向 / 沿轮廓连续带先解方程 / 缩放约定 /
    悬空件诊断三步 / 同一次渲染同一 list 不能 emit 两次 / 铺装带不重叠 / 轴视近景保塔冠塔基）**见 skill**
