## 5. 检查并交回结果

- 未登录请求应被拒绝并返回 401。
- 已登录请求应通过身份校验并进入模型调用。
- 校园建议成功时返回 `kind=answer`、`generated_by=auv`。
- 事件分析成功时返回 `kind=event`、`generated_by=auv`。
- 上游服务不可用时应返回明确错误，不能用假回复冒充真实模型结果。

## 数据范围与故障处理

地点表是 66 个校内地点，已与项目 ID、名称对应。模型地点只作为候选，实际地点由原文或用户手动选点校验；严重度和估计分钟数不作为确定事实。事件分析仅生成草稿，不自动发布热点。

| 现象 | 优先检查 |
| --- | --- |
| AutoDL HTML 404 | 推理服务启动、端口映射、最新地址 |
| 模型鉴权失败 | AUV 密钥是否一致 |
| Supabase 函数 404 | 项目、函数名称和部署结果 |
| Supabase 401 | 用户会话、JWT 配置和函数日志 |
| 超时 | GPU 在线状态、冷启动或网络 |
| 动态数据未取得 | `campus_events`、`campus_services` 表与当前用户读取权限 |
