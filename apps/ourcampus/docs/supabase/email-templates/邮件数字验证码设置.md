# 把认证邮件改为中文数字验证码

适用项目：`hkdblizadnkskxslyjyq`，数字校园孪生。

由有项目管理权限的队友打开 [Supabase 邮件模板页面](https://supabase.com/dashboard/project/hkdblizadnkskxslyjyq/auth/templates)。软件的 Publishable key 不能修改邮件模板，无需把管理员密钥发给前端。

## 配置两项模板

| 后台模板 | 邮件主题（Subject） | 正文（Body） |
|---|---|---|
| Confirm sign up / Confirm signup | 数字校园孪生 · 注册验证码 | 把 [signup-confirmation.html](signup-confirmation.html) 的完整内容粘贴进去并保存 |
| Reset password / Reset Password | 数字校园孪生 · 重置密码验证码 | 把 [password-reset.html](password-reset.html) 的完整内容粘贴进去并保存 |

正文使用 `{{ .Token }}`，由 Supabase 为每次申请生成实际验证码。不要写固定的示例数字，不要保留 `{{ .ConfirmationURL }}` 确认链接。软件已有数字验证码输入与验证接口，不需要关闭邮箱确认。[官方模板变量说明](https://supabase.com/docs/guides/auth/auth-email-templates)

保存后，在软件里重新申请一封认证邮件查看效果。**之前收到的邮件不会改变**，请使用新邮件中的验证码。邮件能否成功送达仍取决于项目已有 SMTP 和发送额度。

注册邮件会显示：

> 数字校园孪生 · 邮箱验证码  
> 你的注册验证码是：  
> 本次申请的数字验证码  
> 请返回软件填写验证码，完成注册。

验证码长度与有效期使用服务器实际配置；前端支持 6–10 位数字。上述“本次申请的数字验证码”只是说明，不是需要粘贴到后台的内容，实际正文必须使用 HTML 文件里的 `{{ .Token }}`。
