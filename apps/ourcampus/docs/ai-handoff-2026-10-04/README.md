# CampusTwin · AI 队友交接说明

整理日期：2026-10-04。项目：本校区本校区数字校园孪生。

本包按“数据 → 事件判断 → 上下文组装 → 模型表达 → 手机展示”整理。它包含当前代码和供队友讨论的接入草案，**没有新增或部署 AI 服务，也没有修改线上数据库**。

## 先看结论

| 部分 | 当前项目情况 | 队友需要做什么 |
| --- | --- | --- |
| 用户身份 | 已接入 Supabase Auth；资料表提供昵称与头像，角色单独管理 | AI 服务验证现有登录身份，按用户权限取数据 |
| 校园地点、服务 | SQL 中有地点、地区、服务表和初始化数据；手机地图仍使用前端地点数据 | 核对云端导入情况，接入查询，并保留来源和未知项 |
| 校园事件 | SQL 已定义事件表；手机热点目前仍是本机数据，包含演示事件 | 接入真实发布、审核、有效期和权限流程 |
| 事件引擎 | 有本机有效期判断和演示道路关联；没有服务端 AI 事件引擎 | 实现可检查的筛选、关联、证据整理和提醒规则 |
| 系统提示词 | 当前软件没有 AI 提示词 | 以本包参考模板为起点，接上经过筛选的上下文 |
| AI 模型 | 本仓库没有模型服务、LoRA 权重或训练代码 | 提供实际模型调用方式、部署地址、输入输出协议 |
| 课表、专业、宿舍画像、天气 | 当前未提供这些数据表或接口 | 如要做个性化提醒，先补真实数据来源和用户授权 |
| 消息中心、主动提醒 | 通知表在 SQL 中预留；手机端未接入消息中心或后台推送 | 后续另接调度、去重、个人通知和手机推送 |

“已接入”指已有连接代码，不代表全部真实账号流程已验收。账号及大厅聊天的双账号实机联调仍待完成。其他业务表的线上迁移情况，本次未逐表检查。

## 分工与交付物

| 负责人 | 需要交付 |
| --- | --- |
| 服务器同学 | 核对实际表结构、RLS、角色、事件维护接口与数据来源；确认真实邮箱注册及聊天可用；为 AI 服务安排安全的取数方式 |
| AI 同学 | 鉴权、数据读取、事件筛选与关联、上下文组装、模型调用、结果校验；提供 HTTPS 地址、接口文档、错误示例和部署配置说明 |
| 手机端开发 | 后续新增 AI 入口，携带真实会话调用服务，展示回复/地点卡片，处理“查看地点、导航、官网”等明确动作 |
| 用户/项目负责人 | 确认首版要解决的问题；提供可靠课表等新增数据时，明确来源、权限与有效期 |

### 给 AI 同学的任务摘要

请先基于现有 Supabase 身份和校园地点字段，提供一个可供手机端调用的 AI 查询服务。回答地点、校园服务和真实有效事件的问题，返回文本、地点卡片及可点击动作。缺失的开放时间、路线影响和课表信息应明确说未知。个人提醒、精确绕行时间和主动推送所需的数据与服务尚未齐备，需另行补充。

首版范围是本包供讨论的建议，并非已经实现的功能。截图里的“v6 已训练好”不能证明队友实际模型状态；模型名称、训练成果、接口和机器配置仍需 AI 同学提供。

## 开发前要对齐的事项

- 实际模型名称、调用协议、是否支持结构化输出；模型服务由谁部署。
- AI 对外地址、鉴权方式、超时和费用控制；密钥仅配置在服务端。
- 云端是否已导入地点/服务数据，是否已经有非演示、可追溯的真实事件。
- 第一版是否只做用户主动查询；若要主动提醒，需要单独确定授权、调度和通知交付范围。
- 课表等个人数据从哪里来；当前位置只在用户主动提供且授权后用于当前请求。

## 截图内容的适用边界

动态事实通过查询和更新取得，不把每条施工通知写进模型权重。规则负责时间、权限、状态和可验证的关系，模型负责基于证据组织回答。LoRA 是模型适配方法，并不只限于语气；本项目是否使用它由 AI 同学决定，也不能用它保证实时事实准确。[Hugging Face LoRA 文档](https://huggingface.co/docs/peft/main/conceptual_guides/lora)

“上课 + 施工 = 提前出门”只是业务例子。判断是否影响路线、提前多少分钟，需要课表、可靠路网、真实路线及耗时；规则和模型都不能在这些数据缺失时承诺准确分钟数。

AI 服务应核验用户会话，并保持用户对应的数据权限。若采用 Supabase Edge Functions，可参考其用户鉴权模式；本包未选定或部署该方案。[Supabase 函数鉴权](https://supabase.com/docs/guides/functions/auth)、[Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)
