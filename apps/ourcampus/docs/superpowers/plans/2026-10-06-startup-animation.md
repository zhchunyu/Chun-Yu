# OurCampus 启动动画

目标：按用户指定样式，在黑底上缓慢显现白金色小写 ourcampus，并同时初始化应用。

实施：
- [x] HTML 首屏提供启动层和独立样式；字标显现 2.2 秒，正常至少停留 2.6 秒，随后淡出。
- [x] React 正常挂载；界面、地图和账号初始化完成后结束启动层，最多等待 6 秒。慢网由应用既有错误／加载状态继续处理。
- [x] 桌面手机预览只在 iframe 内播放；每次完整启动播放一次，切换分页或后台返回不重播。系统减少动态效果时简化动画。
- [x] 安卓原生启动背景及 WebView 使用黑色，避免默认白屏；生成 1.5（versionCode 6）APK。
- [x] 检查构建、资源同步和签名，检查新增代码与界面；未增加或运行软件测试。

复用：React、现有地图加载状态、Auth 状态及本机 Android SDK/JDK。不安装依赖，不修改服务端或登录数据。

结果：网页构建、安卓离线 assembleDebug 与 apksigner 验证通过；浏览器实际观察字标显现并退出到可操作地图，画面保存在 docs/screenshots/2026-10-06-ourcampus-startup.png。新版为 debug 签名包；未进行实体安卓启动动画实测。
