# 04-应用开发

C 端产品实现层。

| 子目录 | 说明 |
| --- | --- |
| `frontend/` | 前端应用（Web / 小程序 / 桌面端） |
| `backend/` | 后端服务与业务逻辑 |
| `shared/` | 前后端共享的类型定义、常量、协议 |

## 现状（2026-09-28）

C 端前端已经落地：**CampusTwin 数字孪生演示版**，源码在独立分支 **`campustwin-afternoon`**
（Vite + React 19 + three.js，`npm ci && npm run dev` 即可运行，含 GitHub Pages 部署）。

本目录下另有两条与它相关的工作：

| 目录 | 说明 |
| --- | --- |
| `安全管理模式/` | 安全能力的**独立源工程**（零依赖 + 自带 174 项自检）与整合到 CampusTwin 的说明 |
| `安全管理模式/campus-twin-patch/` | 整合落地的**补丁快照**（14 个文件 + 3 张效果图）；权威源码仍在 `campustwin-afternoon` 分支 |

## 要求

- 需提供**在线演示地址**或**可安装软件包**，方便评审验证
- 需明确技术栈、运行环境、部署方式
- 界面中不得出现学校名称与 Logo
