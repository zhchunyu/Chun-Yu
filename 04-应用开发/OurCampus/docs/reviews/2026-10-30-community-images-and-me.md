# 社区图片与精简个人页验证（2026-10-30）

## 结果与发布边界

2026-10-26 已实施聊天、校园动态与失物附图，以及精简个人页；生产迁移 `community_post_images` 同日部署成功。当前源码版本 1.19/20，线上仍为 1.18/19。本轮未生成或上传 1.19 APK、未发布 versionCode 20 元数据，手机必须安装新 APK 才能获得客户端功能。

图片使用私有 `post-images`，按父消息／上报可见性授权，展示签名有效期 300 秒。撤回会阻止其他账号申请新链接，已签发链接可能到期前仍能使用。图片只用于展示，原有文字 AI 不识图；本轮不测试 AI。

## 自动化与独立复核

- 相关 10 个测试文件共 69 项全部通过，覆盖图片数量／格式／归属路径、上传失败与重试、消息和上报映射、纯图片消息、账号隔离、个人页及图库模态状态。
- 全前端 `npx vitest run --exclude 'server/**'`：398 项，387 通过，11 项既有失败。分布为 campusReducer(3)、campus(3)、mapScene(1)、auvCatalog(2)、locations(1)、routeGraph(1)；本轮未通过修改这些测试或地图数据消除基线失败。
- `npm run build` 通过，仅有既有体积警告；前端构建通过不代表 APK 签名或手机验收完成。
- 独立复核末轮 P1/P2 均已修复，包括图片请求按账号隔离，并由 App 传入当前账号及回归覆盖。

## 生产数据库验证

[部署 SQL](../supabase/18-community-images.sql) 已部署为 `community_post_images`。通过真实 MCP 执行 [事务权限回归](../supabase/18-community-images-regression.sql)，结果为 pass，执行后的合成 Auth 用户及 Storage fixture 均为 0。

回归使用事务内合成 Auth 与 Storage 元数据，随后回滚；检查了旧文字兼容、纯图片／三图、非法数量与路径、对象归属与存在、不可改换附件、幂等重试、禁止覆写、已引用对象不可删除、本人草稿、其他账号可见性、管理员审核及撤回后读权限。它验证数据库权限，不代表真实文件已通过 Storage HTTP 上传。

10 月 26 日部署后读取安全顾问，对 `post-images`、`community_images`、`hall_messages`、`campus_reports`、`storage.objects` 相关结果筛查，未发现新增相关项。既有 `spatial_ref_sys` 等无关警告仍存在，未宣称整个项目零警告。
