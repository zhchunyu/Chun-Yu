# 返回操作验证 · 2026-10-14

## 行为

- 页面返回按钮、Escape、浏览器返回和 Android 返回统一按层级关闭当前页面或表单。
- 服务子页回到服务；社区子页回到社区；失物发布表单先关闭表单。
- 从服务或社区查看地图地点，关闭详情后回到原来的目录或社区子页；取消由这些页面发起的路线也回到原页。
- 返回首页后不再拦截返回，Android 可执行正常退出/退到后台行为。
- 网页从左右 24px 边缘向内滑动至少 72px 时返回，滑动过程中显示边缘箭头；超过 700ms、明显纵向滑动、短滑或多指操作不返回。
- 网页手势排除腾讯地图、备用二维地图、三维地图、图片查看器、视频和输入控件。
- Android 使用系统返回手势，不同时启用网页自定义手势，避免一次操作重复返回。
- 登录、反馈、失物保存、课表读取、评价及餐厅管理提交期间消费返回事件，保持当前表单。

## 实现范围

新增 `src/app/backNavigation.js` 与 `useBackLayer.js` 管理返回层和单个临时浏览器历史条目；页面关闭后清理历史，避免反复进入页面积累失效记录。仅记录是否可返回，不把表单内容、账户或业务数据写入浏览器历史。

在 Android `MainActivity.java` 中通过现有 AndroidX `OnBackPressedDispatcher` 接入网页返回处理；无须新增插件或依赖。实现参考 [Android 官方返回导航说明](https://developer.android.com/guide/navigation/custom-back)。

## 验证证据

- `npm run test -- src/app/backNavigation.test.js`：7 项通过。覆盖顶层优先级、浏览器连续返回、按钮关闭后的历史清理、清理期间打开新页面、忙碌表单、刷新后的旧历史、手势阈值及地图/多指排除。
- `npm run build`：通过；保留原有大包体积警告。
- 使用已有 JDK21 执行 `android/gradlew.bat :app:compileDebugJavaWithJavac --offline --console=plain`：`BUILD SUCCESSFUL`。默认 JDK17 的首次尝试因工具链要求 21 失败；未安装运行时或改动系统配置。
- 本地手机预览实际操作：浏览器返回从 AI 回到服务；失物页头返回先关闭表单，再用浏览器返回回到社区；服务目录打开图书馆详情，经 Android 使用的网页入口返回原服务目录；返回首页后该入口返回 `false`，历史状态为空。
- 在浏览器中派发 `Touch`/`TouchEvent` 模拟左右边缘手势：两侧均返回服务首页；短滑、纵向滑动保持目录；地图容器上的模拟拖动保持地点详情。内嵌浏览器不支持 CDP 原生触摸输入，以上为 DOM 触摸事件模拟。
- 只读代码审查发现并修复：通知覆盖 AI/课表时的返回优先级、备用地图容器排除、失物表单返回按钮与保存保护。
