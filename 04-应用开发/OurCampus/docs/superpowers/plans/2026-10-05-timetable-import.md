# 我的课表导入实施计划

目标：在安卓和浏览器的「我的」中导入本校区教务导出的 XLS 个人课表，并按教学周查看、将所选周课程带入现有 AUV 助手。

实现：复用现有 React portal、账号和 AUV 请求，不安装新依赖，不把个人课表打包成公共示例，不调用学校受保护接口。导入在本机完成，保存在按账号隔离的 localStorage。

- [x] `src/data/timetableImport.js`：有限制的 XLS BIFF8 读取、当前学校网格归一化；同格多课程和离散周次完整识别，无法识别时拒绝导入，不静默丢课。
- [x] `src/data/timetable.js`：存取、教学周筛选、时间冲突、AI 周课表文本。用户给出的 2026-08-30 保留为起始日期，因周日冲突，只允许按教学周浏览，不推断实际日期。
- [x] `src/features/timetable/TimetablePage.jsx` 和 `timetable.css`：选择文件、预览和确认替换、周次切换、课程及缺失时间提示、起始日期设置、AUV 入口、键盘及手机适配。
- [x] `MePanel.jsx`、`App.jsx`、`AuvAssistantPage.jsx`：入口及 AI 草稿传递；账号变化不带入前一账号课程。
- [x] 以提供的真实 XLS 作导入检查，核对 9 门课程、21 条安排、6 个时段及 1 门未排时间课程；构建并检查浏览器导入和重新打开。原文件不改动，不提交个人数据。

当前范围：支持当前教务格式的 `.xls`；不承诺自动同步教务、不建立共享课表表、不自动把 4-107 等教室编号绑定地图建筑。AI 建议需用户自己审核，本次不自动写入日程。
