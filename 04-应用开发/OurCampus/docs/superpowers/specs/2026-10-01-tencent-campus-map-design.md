# 腾讯地图校园底图试接入

## 目标

在 CampusTwin 的手机地图首页试接入腾讯位置服务的 2D JS API GL 底图，继续展示校园地点标签，并验证免费配额下地图与步行路线服务的可用性。

## 方案

- 使用腾讯 JS API GL 渲染底图，中心定位山西农业大学太谷校区；地图手势由腾讯 SDK 处理。
- 用当前校园引导图中 5 个已匹配的地标和腾讯地点搜索返回坐标拟合平面坐标变换，把现有地点位置映射到腾讯地图。来源不明或地图 API 加载失败时，保留校园引导图回退。
- 普通步行路线优先请求腾讯 WebService 路线 API；无配额、网络失败或超时时沿用 CampusTwin 当前路线。避开施工、无障碍、避雨和夜间安全等校园专属模式继续使用本地校园路网。
- 读取 `VITE_TENCENT_MAP_KEY`；Key 只存在本地 `.env.local`，不写入跟踪文件。腾讯地图底图带有腾讯原生版权标识。
- 地图加载错误、Key 授权错误和接口配额错误以短提示说明，同时允许切回校园引导图。

## 验收

1. 在当前 Vite 手机预览中显示太谷校区腾讯 2D 地图，单指拖动、缩放和双指旋转由地图 SDK 响应。
2. 搜索或选择校园地点时，地图可以聚焦对应位置，已启用的校园标签和当前路线端点可见。
3. 普通步行路线成功时绘制腾讯路线；接口失败时显示本地校园路线状态，不能把失败路线冒称为腾讯路线。
4. Key 或网络不可用时，本地校园引导图仍能正常显示；不得输出或提交 Key。
