# 06-竞赛材料

7 项提交物的成稿区。**只放定稿，草稿放 `99-临时工作区/`。**

| 子目录 | 提交物 | 格式要求 |
| --- | --- | --- |
| `01-作品名称与简介/` | 作品名称 + 作品简介 | 名称 ≤20 字；简介 ≤500 字 |
| `02-技术方案书/` | 技术报告 | PDF，≤10MB，建议 3000–5000 字 |
| `03-演示视频/` | 演示视频 | MP4，3-5 分钟，≤300MB |
| `04-答辩PPT/` | 答辩 PPT | PDF |
| `05-佐证材料/` | 论文/专利/软著/获奖/用户反馈/媒体报道 | PDF，合并为一个文件 |
| `06-源码包/` | 代码与数据（源代码/模型数据/可执行程序） | 分模块清晰划分 |

## 命名规范（网盘大文件）

```
参赛团队编号-场景创新-作品名称-XX（材料名称）
```
