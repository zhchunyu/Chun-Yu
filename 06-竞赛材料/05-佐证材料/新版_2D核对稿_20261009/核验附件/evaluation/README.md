# AUV评测包

本包将当前代码逻辑、故障处理和真实模型质量分开。所有题目属于规则化编写的合成场景，不是用户问卷、真实聊天或现场事件。

## 已执行的离线测试

- formal_cases.json：240项，地点120、消息分流40、资料传递60、异常20。
- offline_before_results.json：修改前快照的完整结果。
- offline_results.json：当前源文件的完整结果。
- 两份summary：汇总、题目校验值和失败条目。
- 地点题注入同一份故意带错误地点的输出，评价系统是否采用原文/选点。资料题注入占位回答，只评价传入资料，不评价回复语义。
- 题目存在模板重复；20项同组题不等于20种独立任务。当前4项消息分流失败保留，不据此声称泛化性能或AI模型准确率。
- development_cases.json：60条近义调试样例，不能作为独立留出集，本轮未用它调参。
- 与仓库训练输入检查完全相同字符串为零；未完成近义重叠审阅和第二位人员的标准答案审核。

复跑（使用Node 22.12以上）：

```powershell
node run_offline.mjs
node run_offline.mjs --baseline
```

脚本当前引用本机工程路径。迁移电脑时修改文件开头的工程路径；修改前快照位于核验附件的source_before。运行后会重写本包结果文件，请在不同输出副本复跑并保留原结果。

## 已准备但未执行的在线质量测试

online_quality_cases.json有180条：事件120、建议60。这里按当前接受字段评分；不把严重度和预计等待时间当作当前App已提供的能力。问答需要同一资料快照和人工评分，不以模型给自己打分作为唯一结论。

online_runner.mjs默认不联网。真实模型、地点表、标准答案二审和私有配置准备好后，由负责人启动。每次保存所有输出与请求失败，不择优重试。配置不要放公开目录，不在聊天中发送密钥。

私有配置字段：mode（direct_model/app_gateway）、base_url、api_key、model_identity、gold_reviewed（真实二审后才为true）、cases_file、extract_model、persona_model；网关模式另需现有专用测试账号的access_token和publishable_key。地址/模型名称以实际部署为准，不能只填脚本里的示例。运行前确认服务资源与调用许可。

```powershell
$env:AUV_EVAL_CONFIG_FILE = '本机私有配置文件绝对路径'
node online_runner.mjs --execute
```

## 人工评分与补充检查

两名评分者隐藏回答来源，分别按事实40、相关20、可执行20、清晰10、不确定信息10评分。保留分项评分和分歧。严重错误单列，不能被平均分掩盖。提示词注入题目前只验证数据进入资料字段，未证明模型拒绝恶意指令；必须用真实模型另测。

需要真实服务另补：响应耗时分布、超时比例、真实地点卡片操作、资料缺失时是否编造、实际模型身份、模型原始字段的单独准确率。Node离线运行耗时不能作为在线响应时间。
