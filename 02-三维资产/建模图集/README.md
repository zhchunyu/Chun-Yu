# 建模图集（交付层面）

供**技术方案书 / 答辩 PPT** 取图的建模成果陈列。是"三维建模层面"的对外交付，
不含方案书正文、视频、PPT 本身（那些不在建模职责内）。

## 两个版本（**按使用场景选，内容完全一致**）

| 文件 | 大小 | 适用 | 特点 |
| --- | --- | --- | --- |
| `山河大学_三维建模图集.html` | 28 KB | **桌面 / 打印** | 引用 `../renders/*.png` 原图（1600×900 高清）；带 A4 横向打印样式，"打印 → 另存为 PDF"即得 PDF |
| `山河大学_三维建模图集_手机版.html` | 1.9 MB | **手机 / 转发 / 离线** | **单文件**：24 张图已缩放至 1000 px 并内嵌为 base64，**不依赖任何外部文件** |
| `选图清单.md` | 5 KB | 取图参考 | 按用途推荐选图 + 每张一句话说明 + 量化表述 + 合规检查项 |

**文案只维护一份**：两版都由 `make_atlas_html.py` 顶部的 `STAGES` / `METRICS` 生成，
手机版脚本直接 `import` 它 —— 改文案不会出现两版不一致。

## ★ 为什么要有"手机版"

主图集引用的是 `../renders/*.png` **相对路径**，而本项目从工作区目录到图片文件名**全是中文**。
这带来两类现实问题：

1. **在静态预览 / 手机浏览器里图片全部不显示** —— 页面不报错，只是图裂。
   非 ASCII 路径在不同 HTTP 服务下的编码处理不一致（主图集已做**百分号编码**缓解）。
2. **只把 HTML 发给别人 / 发到手机** —— 相对路径指向的 `renders/` 根本不在旁边，必然缺图。

手机版把图片内嵌进单文件 ⇒ 拷到任何设备、任何位置、离线都能看。

★ **单文件版可以随意改名**（比如改成纯英文名），因为它不引用任何外部路径。
★ 但**主图集不能单独拷走** —— 整个 `建模图集/` 必须与 `renders/` 一起搬运。

## 打不开 / 图片不显示时怎么排查

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 页面能开，但**图全是裂的** | 只拿到了 HTML，`renders/` 不在旁边；或服务端不认中文路径 | 用**手机版**（自包含）；或起本地服务（见下） |
| 页面**完全打不开 / 白屏** | 文件路径含中文，某些预览器/浏览器处理不了 | 用**手机版**并改名成纯英文；或起本地服务 |
| 手机上字被切掉、要左右拖 | 窄屏下宽表格会横向滚动 | 这是设计如此（三列表格在 390 px 屏上无法完整显示）；表格可左右滑动 |

### 起本地服务（最接近"网页版"的方式）

```bash
cd 02-三维资产
python -m http.server 8130 --bind 127.0.0.1
# 然后浏览器打开 http://127.0.0.1:8130/建模图集/山河大学_三维建模图集.html
```

以 `02-三维资产/` 为根，`建模图集/` 与 `renders/` 的相对关系就成立了，原图能正常加载。
★ 只绑 `127.0.0.1`，不要绑 `0.0.0.0`。

## 与「总览页」的区别

| | `renders/总览_R0-R6.html` | 本图集 |

## 重新生成

```bash
cd 02-三维资产/blender/scripts
python make_atlas_html.py      # 桌面版（自带断链校验）
python make_atlas_mobile.py    # 手机版（需要 PIL：用 envs/default 的解释器）
```

改叙事文案 → 改 `make_atlas_html.py` 顶部的 `STAGES` / `METRICS` 两张表。

## 版式体检（改完排版建议跑一次）

```bash
cd 02-三维资产/tools
NODE_PATH=<node workspace>/node_modules node _measure_layout.cjs <url> 390 844
```
输出：**图片加载数**（"图片不显示"的唯一可靠判据）、**有无横向溢出**、
以及所有比视口宽的元素（在可横向滚动的容器里属正常）。

★ 别用 Edge `--headless=new --screenshot --window-size=390,900` 判断窄屏版式 ——
它会在较宽的视口渲染后裁切，**看起来像"文字被切掉"，实际布局是好的**（已实测）。
