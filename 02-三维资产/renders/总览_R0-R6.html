统一前后对照

R0 / R1 / R2 / R4 / R5 五行是三栏，R6 是单栏 —— 这些阶段在"统一光照"之后又各改过一轮。 三栏统一读作：① 旧光照 → ② 统一后·上一版 → ③ 统一后·现版。
一、旧语言清障（R0 / R1 / R2）
· R0（`clear_old_language_r0.py`，20 个构件）：牌坊群 / 东西阙 / 石狮 / 明堂地雕·灯柱·灯亭 / 案山方亭 / 钟楼。R0 是"语言样板"，成图里必须看得清新塔本身； 未清障时 正立面 的塔身下半被钟楼整个遮住。
· R1 / R2（`build_campus_r1.py` 的 `_DROP` 增补）：钟楼。 它的拆除原先只写在 r3 里，于是 R1 / R2 成图一直带着它 —— R2_图书馆_中轴 里那座孤零零的旧钟楼就坐在新图书馆前庭广场上 （`diag_grid.py` 实测中心行左端命中 BLD_人文_Bell_Tower_屋面）。
清障边界：只删 V2 已定"拆除 / 取消"的构件；图书馆、大礼堂、美术馆、书院属于 "改造"（原地重建为新语言），保留旧版作为"改造前"语境。
二、桥下深色带（R4 / R5）
环廊纵梁截面 _BEAM_D 1.55 → 1.05。原截面下"桥面板底 0.55 + 纵梁 1.55" 在侧视角合成一条 2.10 m 高的实心近黑带（纵梁 M_墨灰钢构 反照率 0.082， 全园最深一档），读作"一块黑板"而不是结构。5 变体 A/B 实测：改材质只是把"黑块"换成"白块"， 带高不变、仍是一整块；压截面后带高 1.60 m，梁与板的关系才读得出来，且保留 V2 的材料分工 （钢构 = 结构，清水混凝土 = 围护）。详见 99-临时工作区/AB_桥下深色带/对照.html。
② 一栏一律保留改动前的版本，方便对照。
三、R6 滨水基座（单栏）
R6 是"统一光照之后新增"的阶段，没有旧光照存档可对照，因此只有一栏 （硬凑两栏会写出一条 404 的 <img src>）。它把原先 Z_TOP 3.0 → Z_BANK −3.4 的 16 m 自然草坡（21.8°，不可上人） 改成一条 2618.7 m 连续挑台：台面 Z 2.40、板厚 1.00、内缘落在地面上（不留缝）、 常态外挑出水 3.0 m，四处节点按弧长分数放大到 13~16 m 宽。
四、配色重标 V2.4（全园 63 张，②→③ 的差异里也含这一项）
palette_retune.py 此前对 53 个材质里的 32 个静默失效： make_mat(noise_scale>0) 会把 Noise→ColorRamp 挂在 Base Color 上，而重标只写 default_value —— 连线优先，写入被忽略， 且异常被吞 ⇒ 不报错、无效果。中招的恰是占画面最大面积的那批： M_清水混凝土 / M_混凝土楼板 / M_桥面 / M_广场铺装 / M_区_*（偏差最大 M_桥面 0.393→0.258）。 V2.4 改为改连线源头（ColorRamp 端点色，只动前 3 通道并整体平移以保住噪声质感）。 全量重渲后实测（63 张，下半图）： 暖% 均值 10.75 → 14.36、冷% 均值 45.84 → 42.01、「冷−暖」+35.08 → +27.65， 63/63 张全部变暖；而 Δ亮度均值仅 −0.49（整体明度几乎不变，说明动的是冷暖比不是明暗）。
⚠ ② 栏是在 V2.4 之前渲染的（那些中间几何状态已不可复现 —— 清障逻辑写在 STAGE_EXTRA 里，旧态没有 config），所以 ②→③ 的差异同时包含几何改动与配色重标两项， 不宜当作单一变量的对照。
五、占位体块压暗（V2.4 补丁）
主动视觉巡检（把 63 张做成接触表一次看全）发现 R4_环廊_鸟瞰 / R3_书院_鸟瞰 里散着二十来个纯白盒子。根因：场地脚本建的 28 栋 分区占位体块（M_体块_*，六分区分色）基色是 0.51~0.65， 比清水混凝土（0.368）还亮近一倍，而 _RETUNE 表里从来没有它们 ⇒ 在 sun_strength 5.8 + exposure +0.20 下直接曝成纯白，整张图读起来像"白模"。
修法：六个体块材质一并压到 0.254~0.324（约原值 ×0.5），保留原来的冷暖色相差异 （人文/教学/生活偏暖，科技/运动偏冷，实验中性）。判据：占位体块应当"比清水混凝土略暗" —— 它们是"既有 / 待改"的体量，不是新建筑；比真建筑亮就是"白模"，比它暗太多又会变成一排黑块。
A/B 实测（5 个代表机位）：平均差 0.98~4.01 / 受影响像素仅 1.6%~7.0% / 最大差 65~67 / Δ亮度 −1.0~−4.0 ⇒ 是局部变化，不是全图偏移，与"只有盒子变暗"完全吻合。

配色度量口径：暖 = 像素 HSV 色相落在 20°~70° 且饱和度 > 0.12 的占比； 冷 = 色相 160°~280° 占比；暗 = 明度 < 0.12 的占比。三者互斥，同一像素只计入一类。
可复现性：同配置跨进程连跑 3 次，暖/冷/暗统计完全一致（12.07 / 25.11 / 2.67）， 渲染为确定性过程；归档版差异全部来自光照统一本身，与随机性无关。
