# 山河大学（主线项目）

**完全虚构**的校园，不对应任何真实学校。借鉴著名建筑只取**设计语言与形制逻辑**，
不出现任何真实学校的名称、标志或可识别元素（合规红线）。

- 设计依据：`01-产品设计/山河大学_设计任务书.md`（含 D1~D10 决策 + 总平面格局定案）

- 场地骨架工程：`blender/projects/山河大学_场地骨架.blend`

| 约定 | 值 |

### 阶段 0 的三个"看不见但致命"的坑

1. **开放曲面的法线是随机的**。岸坡、驳岸、对岸、水翼都是非闭合网格，
   `recalc_face_normals` 只保证彼此一致，不保证朝上 → 渲出成片的死黑色块。
   场地曲面一律 `flush(..., up=True)`（内部 `_force_up()` 把 `normal.z < 0` 的面翻正）。
   **不要用在建筑体块上** —— box 的底面本来就该朝下。
2. **俯视机位的滚转角是退化的**。视线接近垂直时 `to_track_quat('-Z','Y')` 结果不可控
   （画面被转 90°），必须用 `cam_rot` 显式欧拉角。
3. **同心环网格会把"对岸"铺成一整圈** → 总平面读成环形护城河。
   `land_mask(y)` 把南半边远岸沉到水下，河湾向北敞开；桥的远端另补一块
   **水口砂**（`SITE_水口砂`）落脚 —— 风水上水口本就要有砂锁气。

### 定位锚点（D9 场景接口）

命名约定：`BLD_<分区>_<Name>` / `SITE_*` / `ANCHOR_<Name>`，按功能区归 Collection。
`ANCHOR_*` 为 Empty（`PLAIN_AXES`），共 19 个，供队友接 AI 定位与人流热力。

## 多段建模脚本串联（`build_extra`）

场地脚本是**一条长流水线**，后面的建筑脚本不该把它抄一遍。`run_campus.py` 支持
在场地脚本之后按顺序再跑若干个阶段脚本，**共享同一个 globals**：

```json
{"blend": "山河大学_中轴尽端.blend",
 "build_extra": ["build_campus_stage1.py"],
 "jobs": [...]}
```

于是阶段脚本里可以直接用 `W()` / `box()` / `new_obj()` / `make_mat()` /
`emit_to()` / `Z_TOP` / `C_BLD` / `M_PAVE` —— 不必抄常量（抄一遍迟早会和
场地脚本走散）。每个阶段脚本开头先用**前缀匹配**清掉阶段 0 的占位体块：

```python
_DROP_PREFIX = ('BLD_人文_Library', 'BLD_人文_Zhenshan_Tower')
```

## 阶段 1：中轴尽端核心（图书馆 + 镇山塔）

工程：`blender/projects/山河大学_中轴尽端.blend`　脚本：`blender/scripts/build_campus_stage1.py`

| 构件 | 关键尺度（自 `Z_TOP` 起） |
| --- | --- |
| 图书馆台基 | 三层 112×80 / 106×74 / 100×68，顶面 +4.20 |
| 图书馆主体 | 一层 86×56（4.20~13.60）／二层 72×44（~22.40）／三层 56×32（~29.40），**层间首尾相接** |
| 图书馆腰檐 | 三层，出檐 6.5 / 5.5 / 5.0 m，四角起翘 0.85~1.05 m |
| 图书馆大屋顶 | 内环 28×1.2 @ +40.60，外环 52×28 @ +33.40（**起坡 36°**），正脊 +41.80（脊内嵌玻璃采光带） |
| 镇山塔 | 月台 58×58 → 须弥座三级 → 七层塔身（30 → 15.6 m 逐层收 2.6）塔身 +58.9，含刹 **+80.6 m** |
| 塔腰檐 | 七层，出檐 3.2 m，板厚 0.52，起翘 1.30 m |
| 塔院 | 124×124 铺装 + 三面矮墙（南向留口）+ 八座石灯（r = 44 m） |

**高度关系是这一阶段的硬约束**：图书馆压到 41.8 m、塔抬到 80.6 m（**1.93 倍**）。
首版塔只有 70.4 m 而图书馆 41.2 m，从中轴看过去塔被图书馆的屋顶吃掉大半，
"镇山"完全立不起来。

**光影参数（阶段 1 定案，后续阶段沿用）**：
太阳高度 **38°** / 方位 **240°**（西南侧光）/ 强度 **4.2**；天空 **0.85**；曝光 **−0.25**；
空气 **1.0e-5**；云 `cloud_strength` **3.2** / `cloud_scale` **2.2**。

### 阶段 1 的六个坑

1. **坡屋面薄壳的法线不能交给 recalc，而且内环必须封底**。"上表面 + 外檐边 + 平檐底"
   是开放网格，`recalc_face_normals` 只保证彼此一致、整体朝里朝外随机；`up=True`
   又救不了竖直的外檐边（法线 Z 分量为 0）。→ `roof_ring()` 三张面全部按环绕方向
   **手推法线**，调用方传 `recalc=False`。
   **只做这三张面还不够**：内环围出的那块矩形是漏的，低机位会从洞里看到檐下的
   阁楼白墙（本阶段表现为仰视图上屋顶中段一道浅色带，肉眼极难归因）。
   → `cap_hole=True` 补一块朝下的封底板，**倒序取点**才得到朝下的法线：
   `faces.append([o4 + (k - 1 - i) for i in range(k)])`。
2. **檐底要做成平的**。斜檐底会在墙顶与屋面之间留出一个越靠外越大的空腔，
   低机位能从檐下看穿进室内。平檐底把空腔压成一条缝，同时天然形成"檐下天花"。
3. **大屋顶的起坡必须够陡**。首版内环只比外环高 4.8 m（约 22°），
   在仰视与中轴视角里整块屋顶被压成一块平板。抬到 7.2 m（约 36°）才立得起来。
4. **瓦面的高光要掐掉**。36° 的屋面在 300 m 外、20 m 高的机位上是极掠射角，
   粗糙度 0.58 的介电面会把整片天空镜面反射进来，屋顶顶面比白墙还亮。
   → 粗糙度 0.80 + `Specular IOR Level` **0.03**。
5. **屋脊要窄，而且采光带要"嵌"不要"叠"**。首版内环 32×2.8 + 正脊 4.0 m 宽 +
   光庭 26×5×2.6 方盒，斜俯视读成"屋顶上摆了一只托盘"。
   → 内环收到 **28×1.2**、正脊 **1.6 m**；光庭不要做成立在脊上的独立盒子
   （仰视会读成"悬空的盒子"），而是把正脊拆成**左右两条 0.20 m 窄边**、
   中间 1.20 m 嵌入玻璃采光带，**与正脊同高同底**（40.60~41.80），
   这样脊底是一整条连续的 1.6 m 面。
6. **整张图"均匀灰蓝"未必是曝光问题**。本阶段先后排除了曝光和色调映射
   （`AgX` 实测更灰更平），真凶是**程序化积云的水平遮罩只覆盖了高仰角**——
   建筑立面机位普遍只有 1°~7° 仰角，云量被压到 0~0.5。
   → 遮罩放宽到 `(0.010, 0.105)`，并把云提到 `strength 3.2 / scale 2.2`。
   详见 `blender-socket-modeling` skill 的「天空、云与太阳方位」一节。

**定位方法**：这类"看得见但说不出是什么"的伪影，不要靠裁切猜。写脚本按目标像素
反算 NDC 方向打 `scene.ray_cast`，直接打出命中对象名：
```python
d = (fwd + right * (sx * half_w / LENS) + up * (sy * half_h / LENS)).normalized()
hit, loc, nor, idx, ob, mx = sc.ray_cast(dg, CAM_POS, d)   # 物体在 [4]
```
本阶段就是靠它把"浅色带"从"瓦面高光"一路排除到"阁楼白墙"。

**取景要算**：塔刹出画了两次，都是因为没算 `atan(h/d)`。
`上边缘仰角 = 朝向仰角 + atan(sensor_h/2/lens)`，拿它和最高点的仰角比。
注意**相机后退会让远处高塔的相对仰角不降反升**，这种情况要**降焦距**或**抬 `cam_tgt`**。

另：`pyramid_roof()` 的底环→腰环面序必须是 `[底i, 底j, 腰j, 腰i]`；
写成 `[底i, 腰i, 腰j, 底j]` 会得到朝内朝下的法线（瓦面本来就黑，肉眼几乎看不出，
但明暗是错的）。

| --- | --- |
| 主校门牌坊 | 四柱三间五楼。中柱顶 12.00 / 边柱顶 10.20；明楼脊 **19.60**、次楼脊 16.20、边楼脊 14.60 |
| 牌坊柱 | 方柱 2.70 → 2.15 收分（**分 12 段**）+ 柱础 + 夹杆石；匾额为**空白石板** |
| 东西阙 | 基座 13.6 → 阙身三段收分 9.2 / 8.3 / 7.4（高 11.0，两圈枋子层）→ 阙顶脊 14.15 → 宝顶顶 15.30 |
| 石狮 | 牌坊南 46 m、X = ±36：地台 + 须弥座 + 身 + 头（朝南）+ 尾 |
| 中轴御道 | 中轴大道中央 15 m 用两条 1.0 m 石线框出；灯柱 X = ±16.5、间距 26 m |
| 明堂广场 | 椭圆 118×74；中央三重同心圆地雕（r = 20 / 14 / 8 + 中心 3.2）；四角灯柱 (±86, ±50) |
| 案山亭 | 土丘顶（+9.0）方亭：台基 12.5 → 柱距 ±4.0 / 高 3.80 → 攒尖 6.40×3.10 → 宝顶；亭顶 **+21.6 m** |

### 阶段 2 的六个坑

1. **牌坊的柱高必须"中高边低"**。明间柱 12.00、次间柱 10.20 ——
   只有中柱比边柱高，明楼屋面（檐口 13.60）才能压住次楼正脊（13.20）。
   柱高一致的话，次楼脊会从明楼檐口里穿出来。
2. **明楼—次楼—边楼要做三级跌落**。首版把边楼也放在檐口 10.80，
   三段檐口连成一条直线，整座牌坊读成"一条长廊"。→ 边楼降到 10.20。
3. **柱身收分要分够多段**。5 段时每段宽差 0.1 m，近景会在柱身上读出一圈"竹节"台阶。→ 12 段。
4. **斗拱后面必须有芯板**。不加的话，近景能透过斗拱块之间的缝直接看到天空，
   整层斗拱读成一排"竖栏杆"。→ 加一块 0.40 m 厚的通长芯板。
5. **阙要有"枋子层"**。光秃秃的方柱 + 屋顶在近景读成"现代岗亭"。
   → 阙身加两圈凸出的横带（比柱身宽 0.3~0.7 m），把柱分成三段。
6. **牌坊那一带的树要横着排干净**（±100）。首版只排到 ±74，
   前导广场两侧的行道树正好卡在次楼、边楼前面，整座牌坊被树埋掉一半。

**匾额一律留空白石板**（合规红线：不出现任何题字）。

另：`run_campus.py` 的 `build_extra` 循环**必须把 `run()` 的返回值回填给 `g`**。
`run()` 是往一份新字典里 `exec` 的，不回填的话阶段 3 就拿不到阶段 2 定义的
`emit_to` / `roof_ring` 这些工具函数（阶段 1 侥幸能跑，只是因为它是第一个 extra）。

## 工作流

1. **参考**：从官网/公开渠道抓实景照片，归档到 `references/<建筑>/`，
   用 `tools/crop_detail.py` 裁切关键部位放大核对
2. **建模**：`blender/scripts/build_<资产>.py` 程序化生成（不用布尔运算）
3. **渲染**：`blender/scripts/render_<资产>.py`（参数可被 `RENDER_CFG` 覆盖）
4. **出图**：`run_pipeline.py` 一条命令跑完建模 → 存盘 → 批量渲染

### MCP 实时通道

连通后用 `blender/scripts/blender_bridge.py` 送脚本：`run <file.py>` / `code "<code>"` / `ping`。
