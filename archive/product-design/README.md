# 01-产品设计

从「用户是谁」到「界面长什么样」的完整产品定义链路。

| 子目录 | 产出物 |
| --- | --- |
| `01-需求与调研/` | 竞品分析、痛点清单、需求池、PRD 初稿 |
| `02-用户画像与场景/` | 用户画像、典型场景故事（User Story / 场景脚本） |
| `03-功能架构/` | 功能树、信息架构、AI 能力与功能的映射表 |
| `04-交互原型/` | 低保真线框、可点击原型 |
| `05-UI视觉/` | 视觉规范、高保真界面、设计稿导出 |

> 评分项「功能完整性 20 分」「应用价值 15 分」主要由这一层决定。
> AI 能力必须与产品功能**高度契合**，避免算法与软件脱节。
