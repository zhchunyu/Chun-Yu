## 二、已确认决策

### D1 · 风格基调

**东方山水园林骨架 + 新中式语汇 + 未来科技地标**（1、2、3 的融合）

- 以中国山水园林的格局与风水为骨：背山面水、中轴对位、藏风聚气
- 建筑语汇取新中式：坡屋顶、木构意象、白墙灰瓦、叠石理水
- 在其中插入参数化未来建筑作为**视觉记忆点**
- **排除**欧式新古典（穹顶柱廊那一路不做）

### D2 · 场地地形

**江河半岛 · 三面环水**

- 校园位于河流弯道内侧的半岛上，三面环水，远山为屏
- 仅在陆路一侧开主校门
- 堪舆对应：弯道内侧为「玉带环腰」（吉），来龙自陆路进，水口在下游
- 约束：可用建设用地紧张 → **建筑密度高，天际线需靠塔楼类地标支撑**

### D3 · 校园规模

**中等规模**

| 指标 | 取值 |
| --- | --- |
| 用地面积 | 约 1200 亩（80 公顷） |
| 在校生 | 约 1.6 万人 |
| 主要建筑 | 20 ~ 28 栋 |

半岛用地能完整容纳功能分区（教学 / 科研 / 生活 / 运动 / 景观），
山水格局与中轴线都可铺开，单栋建筑也仍有做精的余地。

### D4 · 半岛内部地形

**平坦半岛 + 人工土丘**

- 场地基本平坦，只在中轴线上堆 1~2 座小型人工土丘做**对景与框景**
  （做法参考颐和园、拙政园的人工叠山）
- 建筑排布最自由、建模最可控
- **代价**：校园没有天然制高点 → **地标塔必须靠建筑自身拔起来**，
  天际线完全由建筑决定，这抬高了地标建筑的权重

### D6 · 地标建筑选型

**东方塔阁 + 未来曲面**（两路并置，形成张力）

| 路子 | 借鉴对象 | 提取的"过目不忘点" | 用在什么建筑上 |
| --- | --- | --- | --- |
| 东方塔阁 | 应县木塔 · 黄鹤楼 · 贝聿铭 苏州博物馆 | 塔阁剪影、层层飞檐、斗拱节奏、现代几何转译粉墙黛瓦 | 中轴焦点塔、图书馆、校门牌坊、钟楼 |
| 未来曲面 | 扎哈·哈迪德 · 哈尔滨大剧院 · 鸟巢 | 流体曲面、连续起伏屋面、结构即表皮 | 体育中心、创新中心、演艺中心 |

**明确排除的两路**（用户未选）：

- 山水地景系（王澍 象山校区 / 宁波博物馆 / 石上纯也）—— 不做瓦爿墙与地景建筑
- 光影几何系（安藤忠雄 / 路易斯·康 / 密斯）—— 不做清水混凝土切光与极简秩序

> 设计含义：校园的视觉张力来自**「木构塔阁」与「流体曲面」的直接对撞**，
> 而不是靠地景融合或材料静谧。中轴线上应以塔阁立骨，功能节点上用曲面破题。

### D8 · 交付形式与精度预算

**流程：先建模 → 网页预览查问题 → 返工 → 打包成 App（队友负责）**

```
建模（本阶段）→ three.js 网页预览（供用户实地查看）→ 按反馈返工 → 导出 GLB 交给队友打包 App
```

由此推导出的技术约束：

| 项 | 取值 | 理由 |
| --- | --- | --- |
| 单栋建筑面数 | 约 10~15 万面以内 | 要在浏览器里转得动 |
| 全场景面数 | 约 200 万面以内 | 同上 |
| 贴图 | ≤ 2K | 同上 |
| 必产出的中间物 | GLB / glTF | 队友打包 App 的输入 |
| 每个建筑阶段的交付 | 渲染图 + 网页可查看 | 用户要求"每完成一个建筑阶段即汇报" |

### D7 · 风水布局力度

**格局为主 · 细节从简**

把传统营建的空间智慧当作**硬性设计原则**用，但不推罗盘吉凶、不涉占验：

| 原则 | 落实方式 |
| --- | --- |
| 主山为靠 | 对岸远山作为中轴尽端的对景与背景 |
| 四象对位 | 玄武（靠山）· 青龙白虎（东西护卫）· 朱雀（明堂开阔） |
| 坐北朝南 | 主体建筑朝向遵循，中轴按南北向组织 |
| 玉带环腰 | 三面环水即天然玉带，滨水岸线全部保留为公共空间 |
| 水口收束 | 河流下游方向植树、堆砂、架桥以"锁气" |
| 镇山 | 中轴线上的人工土丘，兼作对景与框景 |

**不做**：罗盘坐向推演、四象精确方位角、龙强虎弱的高度硬约束。

### D10 · 来龙方位与中轴走向

**由总设计师定，在总平面方案中说明理由。**

已定倾向：

- **陆路（来龙）自南侧接入**，主校门朝南（合传统"南面"）
- **中轴由南向北推进**，尽端对**北面的水面与对岸远山**
- 三面（东 / 西 / 北）环水 → 天然「水抱」之势
- 塔楼与图书馆置于中轴北端，**背水面山**，收头气势最强

理由：三面环水本身已构成「水抱」吉格；若再把中轴收头交给水，
就浪费了远山这个现成的对景。故中轴尽端留给山，水作为环绕的玉带。

### D5 · 学科性格与功能构成

**综合型 · 全学科**（文 / 理 / 工 / 医 / 艺 / 体 全覆盖）

- 主要建筑数量取上限，**约 28 栋**
- 总平面需划出 6~7 个功能区
- 两路建筑语言各归其位：
  - **东方塔阁** → 中轴与滨水的人文区（图书馆、大礼堂、美术馆、书院、校门、钟楼）
  - **未来曲面** → 半岛尖端与外围的科技区（创新中心、体育中心、演艺中心、实验楼群）

### D9 · 与产品功能的耦合

**预留完整场景接口**（网页预览仍以"查看建筑"为主，不做产品功能演示）

建模阶段就要落实的约束：

| 项 | 要求 |
| --- | --- |
| 命名 | 按功能英文命名，如 `Teaching_A` / `Library` / `Dorm_C` / `Stadium` |
| 分组 | 按功能区归入集合（Collection），便于整体显隐与批量替换 |
| 道路 | 道路系统连通、可导航，主次路分级明确 |
| 锚点 | 食堂 / 教学楼 / 操场 / 宿舍 / 图书馆等主要人流节点预埋定位锚点 |
| 朝向 | 每栋建筑的正面朝向与主入口明确（供 AI 判断"人在哪栋楼前"） |

目的：队友后续接 AI 定位与人流热力时**不用返工改模型**。

### 起点选择理由

从**阶段 0 场地骨架**开始，而不是直接从某栋楼开始：

1. 风水格局（背山面水、中轴对位、水口收束）是**全局约束**，
   骨架定了，每栋楼的位置、朝向、体量才有依据
2. 用户明确要求"注意校园整体的风水布局"——格局必须先被看见、被确认
3. 骨架本身也是渲染的舞台：地形、水系、远山、路网一旦成型，
   后续每栋楼放进去都能立刻出图

### 红线（贯穿全程）

- 不出现任何与真实学校相关的标志、名称、校徽、题字、门牌
- 借鉴著名建筑只提取**设计语言与形制逻辑**，不做 1:1 复制，
  不出现可被识别的专有造型或标识

| 光影 | 太阳高度 38° / 方位 240°（西南侧光）/ 强度 4.2；天空 0.85；曝光 −0.25；空气 1.0e-5；云 strength 3.2 / scale 2.2 |

**核心硬约束**：塔必须明显高过楼（本项目 **1.93 倍**）。首版塔 70.4 m、楼 41.2 m，
从中轴看过去塔被楼的屋顶吃掉大半，"镇山"完全立不起来 —— 这是阶段 1 返工的主因。

**迭代中修掉的七个问题**（已同步进 `blender-socket-modeling` skill）：
① 坡屋面薄壳的法线不能交给 `recalc` → 手推法线 + `recalc=False`；
② 斜檐底会在墙顶与屋面之间留出空腔 → 檐底做成平的；
③ 大屋顶起坡 22° 太缓、被压成平板 → 抬到 36°，脊顶收窄到 1.2 m；
④ 瓦面在掠射角把天空镜面反射进来、比白墙还亮 → 粗糙度 0.80 + `Specular IOR Level` 0.03；
⑤ 广场铺装 0.47 在实景光下冲到近白 → 全场铺装压到 0.32~0.40，并加铺装分格线；
⑥ **屋顶内环漏封底**，低机位从洞里看到檐下的阁楼白墙（表现为屋面上的一道浅色带，
   肉眼反复归因失败，最后靠射线诊断定位）→ `roof_ring` 加 `cap_hole=True` 封底板；
⑦ **光庭"飘"在正脊上** → 正脊拆成左右两条窄边（各 0.20 m），中间 1.20 m 嵌入玻璃采光带，
   脊线变成连续的一整条。

**光影与天空另做了一轮专项校准**（4 方案 × 2 机位 A/B）：
首版五张图有四张"整片均匀灰蓝"，先后排除了曝光、色调映射（`AgX` 实测更灰更平）两个嫌疑，
最终定位在**程序化积云的水平遮罩**——原遮罩只覆盖仰角 1.7°~13.9°，而建筑立面机位
普遍只有 1°~7° 仰角，云量被压到 0~0.5。放宽遮罩 + 把云提到 `strength 3.2 / scale 2.2`
之后，白墙才真正读成白墙、天空才有层次。

**本轮实拍暴露并已修的三个形制 bug**（技术经验仍有效，已同步 skill）：

① **机位被同区其它建筑挡住** —— 首版大礼堂/美术馆机位从正南 160 m 处拍，
正中书院 A / 书院 B 的背面（相距仅 46 m），主体完全没入画。
靠一次几何诊断（打印所有 `BLD_*` 的世界包围盒）才定位，**不能再靠读代码猜机位**；
② **大礼堂大屋顶坡度只有 14.6°** —— 内环 Z 定太低（38.00），屋面渲成一块水平板。
内环抬到 40.60 后坡度 20.4°，才立得住；
③ **美术馆屋面是倒坡** —— 外环 Z 写成 `_h + 1.90 - 0.70`，比内环 Z（`_zr`）还高 1.0 m，
檐口比脊还高，渲出来是三片"黑斜板"。已改为四坡攒尖。
④ **书院屋面被压成平顶** —— 长条建筑用"小矩形内环"会在长边方向也放坡，
整个屋顶塌成"平顶 + 一圈薄檐"。长条殿堂应做**悬山**：`hw_in = hw_out`，
长边方向不产生坡度，两端自然落成垂直山面。

**另补**：人文区 6 栋的 `TREE_EXCLUDE` 必须按**实建台基**尺寸重排 ——
阶段 0 的通用循环是按占位体块算的（大礼堂台基 134×100 对占位体块 58×44），
不重排会有行道树直接长进台基和大台阶里。
