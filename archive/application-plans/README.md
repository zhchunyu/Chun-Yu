# 04-应用开发

C 端产品实现层。

| 子目录 | 说明 |
| --- | --- |
| `frontend/` | 前端应用（Web / 小程序 / 桌面端） |
| `backend/` | 后端服务与业务逻辑 |
| `shared/` | 前后端共享的类型定义、常量、协议 |

## 要求

- 需提供**在线演示地址**或**可安装软件包**，方便评审验证
- 需明确技术栈、运行环境、部署方式
- 界面中不得出现学校名称与 Logo

## OurCampus 应用

完整手机应用位于 [OurCampus](OurCampus/README.md)，包含 React 前端、Capacitor 安卓工程、Supabase 接入与 AUV 网关。
