## ② 路 A：LLaMA-Factory API（推荐先走）

先建文件：

```bash
cat > /root/autodl-tmp/start_api.sh <<'AUV_EOF'
#!/bin/bash
set -e
PORT=${API_PORT:-6006}                 # ★ AutoDL 自定义服务默认映射 6006
# ★★★ API Key —— 公网公开服务，这是唯一门锁
API_KEY="${API_KEY:-auv-CHANGE-ME-2026}"
BASE=/root/autodl-tmp/models/models/qwen--Qwen2.5-14B-Instruct/snapshots/master
ADAPTER=/root/autodl-tmp/output/qwen25-14b-auv-v10-extract

export API_HOST=0.0.0.0
export API_PORT="$PORT"
export API_KEY="$API_KEY"

echo "端口 $PORT | 适配器 $ADAPTER | 接口 /v1/chat/completions"
exec llamafactory-cli api \
  --model_name_or_path "$BASE" \
  --template qwen \
  --finetuning_type lora \
  --adapter_name_or_path "$ADAPTER" \
  --quantization_bit 4 \
  --infer_backend huggingface
AUV_EOF
```

然后跑（**Key 直接跟在命令前面传**，不用改文件）：

```bash
API_KEY="auv-你的长随机串" bash /root/autodl-tmp/start_api.sh
```

#### ★ 怎么设置 / 生成 API Key

```bash
# 生成一个强 Key（推荐）
python -c "import secrets;print('auv-'+secrets.token_urlsafe(32))"

# 方式①：命令行传（最省事，不用改文件）
API_KEY="auv-刚刚生成的串" bash /root/autodl-tmp/start_api.sh

# 方式②：export 后跑
export API_KEY="auv-刚刚生成的串"
bash /root/autodl-tmp/start_api.sh

# 方式③：改文件里的默认值
sed -i 's/^API_KEY=.*/API_KEY="auv-刚刚生成的串"/' /root/autodl-tmp/start_api.sh
# 或用编辑器
nano /root/autodl-tmp/start_api.sh     # 改完 Ctrl+O 保存、Ctrl+X 退出
```

★★ **改完 Key 必须重启服务才生效**（`Ctrl+C` 停掉再起）。
★★ **Key 单独发给队友**，不要写进代码仓库、不要下发到浏览器。
★ 验证是否生效：
```bash
curl -s -o /dev/null -w "无Key: %{http_code}\n" http://127.0.0.1:6006/v1/models   # 期望 401
curl -s -o /dev/null -w "带Key: %{http_code}\n" http://127.0.0.1:6006/v1/models \
  -H "Authorization: Bearer auv-刚刚生成的串"                                      # 期望 200
```

> ★ 如果报参数不认识 ⇒ 先 `llamafactory-cli api --help` 看实际参数名（版本间有差异）。
> ★ 想挂 `persona` 就改 `ADAPTER=` 那一行。

cat > /root/autodl-tmp/serve_vllm.sh <<'AUV_EOF'

## ⑤ ★ vLLM 下载太慢怎么办

### 先判断是不是真在动

```bash
du -sh /root/.cache/pip; sleep 10; du -sh /root/.cache/pip   # 两次数字在涨 = 在下
```

### 为什么慢（多半不是卡住）

★★ `pip install vllm` 会**顺带重装一个匹配版本的 torch（约 2.5 GB）**，即使镜像里已经有 torch。
加上 vLLM 自己的 wheel + 其他依赖，**总共 3~5 GB 很正常**。

### 加速

```bash
# ① AutoDL 官方学术加速（最有效，先跑这个）
source /etc/network_turbo

# ② 换国内镜像源
pip install -U vllm -i https://pypi.tuna.tsinghua.edu.cn/simple

# ③ 转后台，不占终端（推荐）
nohup pip install -U vllm -i https://pypi.tuna.tsinghua.edu.cn/simple \
  > /root/autodl-tmp/vllm_install.log 2>&1 &
tail -f /root/autodl-tmp/vllm_install.log
```

### ★★ 别等它 —— 路 A 零下载，现在就能给队友接口

**并行推进**：
1. vLLM 在后台下（上面的 `nohup`）
2. **同时**另开一个终端跑路 A：

```bash
bash /root/autodl-tmp/start_api.sh
```

路 A 只用现成的 LLaMA-Factory 环境，**一个新包都不用下**。链路今天就通。

### 装完记得固化

vLLM 装好之后，到 AutoDL 控制台**「保存镜像」**存一份 ⇒ 以后开机直接用，不用重下。

### ★ 装到哪里？（两种都行，二选一）

| | 简单法（推荐） | 稳妥法 |
|---|---|---|
| 装法 | `pip install -U vllm`（进系统盘） | `pip install -U vllm -t /root/autodl-tmp/pylibs` |
| 风险 | **释放实例**会丢（关机不丢） | 释放实例也不丢 |
| 补救 | **装完立刻「保存镜像」** | — |
| ★ 启动方式 | `vllm serve …` | ⚠️ `vllm` 命令**不在 PATH** ⇒ 必须用<br>`python -m vllm.entrypoints.openai.api_server …` |

### ③ 完整复测（8 条用例 · 两种拼法对比 · 免上传粘贴版）

```bash
cat > /root/autodl-tmp/check_api.py <<'PYEOF'
import json, os, urllib.request
URL=os.environ.get("AUV_BASE_URL","http://127.0.0.1:6006")
KEY=os.environ.get("AUV_API_KEY","auv-CHANGE-ME-2026")
MODEL=os.environ.get("AUV_MODEL","extract")
LOC=os.environ.get("AUV_LOCATIONS","/root/autodl-tmp/campus_locations.json")
INSTR="你是校园事件分析助手。请从用户描述中提取事件的结构化信息，输出JSON格式，包含以下字段：type(事件类型，取值safety/congestion/service/notice)、building_id(建筑ID，与building_name同步，没有则为null)、building_name(建筑名称，描述中未提及地点时填null)、floor(楼层，没有则为null)、severity(严重程度，取值low/medium/high)、description(事件摘要)、estimated_wait_min(预计等待或持续时间，单位分钟，没有则为null)、time_window(时间段，取值morning/noon/afternoon/evening/night/unknown)、advice(行动建议)。注意：描述中没有明确提到的地点、楼层等信息一律填null，不要推测或编造。"
SYS="You are a helpful assistant."
T=[("谷园餐厅现在人多到爆，队都排到门口了","congestion","谷园餐厅"),
("图书馆三楼空调外机看着要掉","safety","图书馆"),
("3号公寓楼楼下洗衣机全是坏的，一个能用的都没有","service","3号公寓楼"),
("崇文楼下周有创业分享会，感兴趣的可以报名","notice","崇文楼"),
("睿智文体馆羽毛球场地今晚约满了","congestion","睿智文体馆"),
("实验大楼门口自行车乱停，都堵住路了","congestion","实验大楼"),
("英语角开始报名了，截止到本周日，要报的抓紧","notice","NULL"),
("有人晕倒了，快来人","safety","NULL")]
N_A=6
locs={}
if os.path.exists(LOC):
    d=json.load(open(LOC,encoding="utf-8"))
    for l in d["locations"]:
        locs[l["name"]]=l["id"]
        for a in l.get("aliases",[]): locs.setdefault(a,l["id"])
    print("权威表 %d 地点"%len(d["locations"]))
else:
    print("WARN 无权威表 => 地点合法率跳过")
def call(m):
    r=urllib.request.Request(URL.rstrip("/")+"/v1/chat/completions",
        data=json.dumps({"model":MODEL,"temperature":0,"max_tokens":256,"messages":m}).encode(),
        headers={"Content-Type":"application/json","Authorization":"Bearer "+KEY},method="POST")
    with urllib.request.urlopen(r,timeout=180) as x:
        return json.loads(x.read())["choices"][0]["message"]["content"]
def pj(s):
    s=s.strip()
    if s.startswith("```"):
        p=s.split("```"); s=p[1]; s=s[4:] if s.lower().startswith("json") else s
    try: return json.loads(s.strip())
    except Exception:
        i,j=s.find("{"),s.rfind("}")
        try: return json.loads(s[i:j+1]) if i>=0 and j>i else None
        except Exception: return None
for mode in ("user","system"):
    print("\n"+"#"*62); print("# 拼法:",mode,"(user=instruction+\\n+text 都放user / system=instruction放system)"); print("#"*62)
    ok=dict(j=0,t=0,n=0,l=0,lc=0,idm=0)
    for i,(txt,et,eb) in enumerate(T,1):
        msgs=[{"role":"system","content":SYS if mode=="user" else INSTR},
              {"role":"user","content":(INSTR+"\n"+txt) if mode=="user" else txt}]
        try: raw=call(msgs)
        except Exception as e: print("[%d] 请求失败: %s"%(i,e)); continue
        p=pj(raw); print("\n[%d] %s\n  期望 type=%s bld=%s\n  -> %s"%(i,txt,et,eb,raw.strip()[:280]))
        if not p: print("  X JSON 解析失败"); continue
        ok["j"]+=1
        gt,gb,gid=p.get("type"),p.get("building_name"),p.get("building_id")
        if i<=N_A:
            if gt==et: ok["t"]+=1; print("  OK type")
            else: print("  X type 应 %s 实 %s"%(et,gt))
            if gb:
                if locs:
                    ok["lc"]+=1
                    if gb in locs:
                        ok["l"]+=1; print("  OK 地点在表内 %s (id=%s)"%(gb,locs[gb]))
                        if gid and gid!=locs[gb]: ok["idm"]+=1; print("  ! id 不符: %s 应为 %s"%(gid,locs[gb]))
                    else: print("  X 幻觉地点 %r"%gb)
                else: print("  ! 跳过地点判定 %r"%gb)
        if N_A<i<=N_A+2:
            if gb is None: ok["n"]+=1; print("  OK null 正确")
            else: print("  X 应为 null 实 %r"%gb)
    print("\n【%s】JSON %d/%d | type %d/%d | null %d/2 | 地点合法 %d/%d | id不符 %d"
          %(mode,ok["j"],len(T),ok["t"],N_A,ok["n"],ok["l"],ok["lc"],ok["idm"]))
print("\n门槛：地点合法率必须 6/6 = 100%，JSON 可解析率 100%")
PYEOF
python /root/autodl-tmp/check_api.py
```

## ⑧ ★★ 想要「打开网页问答」的界面？那是 WebUI，不是 API

**这是两套完全不同的东西，别混：**

| | **WebUI** | **API** |
|---|---|---|
| 启动 | `llamafactory-cli webui` | `llamafactory-cli api …`（`start_api.sh`） |
| 端口 | **7860** | **6006** |
| 有网页吗 | ✅ **有，打开就能聊** | ❌ 没有首页（只有 `/docs`） |
| 给谁用 | **人**（自己试、演示） | **程序**（队友的代码） |

> ★ 打开 API 地址看到 `{"detail":"Not Found"}` **是正常的** —— 它没有首页。

### 起 WebUI

```bash
# 默认 7860
llamafactory-cli webui

# 或指定端口（想让自定义服务不用改配置，就用 6006）
GRADIO_SERVER_NAME=0.0.0.0 GRADIO_SERVER_PORT=6006 llamafactory-cli webui
```

然后在 WebUI 里：**Chat 标签页 → 选基座 + 挂 LoRA → 直接聊**。

### 两个同时开（各占约 10 GB，32G 卡放得下）

```bash
# 终端 1：网页版（人用）
GRADIO_SERVER_NAME=0.0.0.0 GRADIO_SERVER_PORT=7860 llamafactory-cli webui

# 终端 2：接口版（队友代码用）

```

控制台能填两个自定义服务端口就都映射 ⇒ **你聊天、队友调接口，互不干扰**。
