## 提交要求

| 材料 | 官方要求 |
| --- | --- |
| 作品名称 | 不超过 20 字。 |
| 作品简介 | 不超过 500 字，可按问题、方案、效果、应用展开。 |
| 技术报告 | PDF，不超过 10M，建议 3000–5000 字；按七部分大纲编写。论文、证书、测试报告等补充材料另放佐证材料。 |
| 演示视频 | MP4，分辨率不低于 1080p，时长 3–5 分钟。当前成片尚未完成，待补。 |
| 答辩 PPT | 覆盖背景、核心技术、创新点、应用前景；附件未强制限定为 PDF。 |
| 代码与模型数据 | 若有，按源代码、模型数据、可执行程序划分；注明数据来源、用途、格式与运行方法。 |
| 佐证材料 | 合并成一个 PDF，按实际已有材料提供。 |

附件没有规定演示视频必须小于 300 MB；不得沿用其他赛道的限制。作品材料不能出现学校名称、指导教师或队员个人信息；外发前还需检查图片像素、视频画面与音轨、文档元数据及截图。

## 技术报告结构

1. 作品概述：背景与目标。
2. 需求分析：问题与需求调研。
3. AI 技术工具选择与运用。
4. 项目实施：方案、数据处理、训练优化、系统开发部署。
5. 应用成效：实际成果、技术指标和效益。
6. 总结与展望：经验、不足和后续方向。
7. 附录：来源明确的数据、关键代码与模型说明、参考文献。

当前论证主线为校园地点信息、社区协作与 AUV 助手。三维浏览、室内导航及尚未验收的能力属于后续开发，不作为已上线能力或实测成果。模型统计须保留样本范围、分母、失败案例及测试边界。
