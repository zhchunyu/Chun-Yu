## 真实录屏接入

信息流单项位于14秒开始，触发参数以该单项起点为0秒。收到录屏后从真实返回时点填入：

| 参数 | 对应真实动作 |
|---|---|
| entryCommit | 入口提交得到实际反馈 |
| entryResolve | 地点解析返回 |
| entryRefresh | 查看端列表刷新 |
| entryNotify | 真实提醒到达 |
| entryExpand | 通知/详情展开 |
| lostCommit | 拾物上报得到反馈 |
| lostMatch | 查询后实际匹配返回 |
| historyUpdate | 最近更新记录到达 |

新事件0.4秒淡入并上移24像素；地点0.24秒淡入；列表0.32秒只让位一次；摘要到达0.32秒，详情按entryExpand恢复；更新0.32秒淡入并上移12像素，节点0.48秒回稳。来源关系随匹配触发出现，原摘要仍保留。正文完整短句显示，不逐字打出，不加虚构进度。

在没有录屏时，输入阶段只作为后期示意短暂出现，不在整个案例持续显示“正在输入”。本轮用空文字与临时计划触发测试了入场、摘要、列表让位和来源结构，随后**已全部恢复为-1关闭**。
